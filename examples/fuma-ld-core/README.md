# Native diploid LD and explicit windows

Follow [the API guide](../../docs/literature/FUMA_LD_CORE.md) to compile and run
this synthetic example against the validated development artifact. It prints
allele frequencies, a pairwise-complete correlation and distinct window coverage.

This is a library example. The typed BED-to-reference preparation command,
resource capture/replay and automatic locus handoff remain to be implemented.
