# Prepared-set native enrichment example

Read the [component guide](../../docs/literature/GSEAPY_STATISTICS_DEVELOPMENT.md)
for the development JAR and copyable command. The example executes local native
Java over-representation arithmetic with explicit GSEApy edition and background.
It does not contact Enrichr, download libraries or infer gene identifiers.

Display row warnings. An undefined original P value requires a corrected
background or skipping dependent inference. Preserve underflow/nonfinite states;
do not replace them with invented finite values. The complete GSEApy execution
adapter remains separate work and has no catalog credit from this example.
