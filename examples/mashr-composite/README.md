# Reported composite-proxy method

Follow [the native API guide](../../docs/literature/MASHR_COMPOSITE.md).
The eight-column example is synthetic. It demonstrates all-included/none-excluded
scores, an effect specific to one declared condition, an at-least-one score, and
the reported inclusive `0.05` threshold. It also shows a source-rounded zero
whose stable log diagnostic remains finite.

The independence assumption is explicit. These are not probabilities obtained
by integrating the joint mash posterior, and the example does not reproduce a
paper's data, binary edition or unreported fit choices.
