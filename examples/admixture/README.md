# ADMIXTURE examples

`NativeLikelihood.java` runs without an upstream runtime. The JSON templates are explicit original-runtime recipes, not universal analysis defaults. Replace every `REPLACE_WITH` review statement, the data paths and all scientific choices before using research data. Supervised labels must contain exactly one row for every FID/IID, with `-` for unknown references. Projection consumes a completed typed fit output and exact BIM metadata.

For a completely synthetic runnable demonstration, run:

```sh
python3 examples/admixture/make_demo.py NEW_DEMO_DIRECTORY
```

The new directory contains deterministic BED/BIM/FAM inputs, new projection targets, five fully populated recipes and synthetic population labels. Run its `fit.json` to `fit-output` before `project.json`; the other recipes use separate new output directories. An admitted original runtime is required for these fitting commands. No real participants or inferred social identities are represented.

Read [workflow and recovery instructions](../../docs/literature/omics-2023-2026/ADMIXTURE_WORKFLOWS.md). The exact development candidate is recorded in `admixture-adapter-validation.json`. The canonical executable and public release are separate.
