# Native sharing summaries

`Example.java` fits three synthetic features with an explicit Gaussian prior,
then demonstrates strict posterior-mean sharing, an empty selection, an undefined
selected ratio, and the separately gated product of marginal sign scores.

Compile and run from the repository root with the development artifact identified
in [the guide](../../docs/literature/MASHR_SHARING.md). The example uses no R,
external software, downloaded data, patient data, or inferred missing values.
It is a library example; public summary/study routes remain open.
