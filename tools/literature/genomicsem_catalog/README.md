# GenomicSEM source-role admission

This package admits one original GenomicSEM upstream family and five reviewed
uses, using the immutable preparation and fitting qualifications. It keeps
all 250 paper identities, 2,724 observations, unrelated tool records and the
1,760 earlier review objects intact. GenomicSEM moves from method overlap to
an upstream adapter: missing tools stay at 254, while method overlap falls
from 18 to 17. No extra native, dependency or per-function credit is added.

The existing source audit remains unchanged. Applied copies preserve the
literal 0.5.0, 0.0.3f and 0.0.5 contexts, unreported editions and raw near-name
captures. Historical author editions and original analyses remain unqualified.
Read [the workflow guide](../../../docs/literature/GENOMICSEM_CATALOG_WORKFLOWS.md).

`close_genomicsem_catalog.py` has explicit plan, inspect, apply and verify
modes. A new output path, exact producer, original physical source context,
private evidence and full primary XML cache are required. Applying a saved
plan rechecks its source, original metadata, complete manifest, preview,
registry and qualification. The reused atomic installer preserves concurrent
changes and retains rejected bytes on rollback.

The full prior saved reader was actually run against the preserved physical
context before admission work. Every mode checks all 109 source-context files
against the exact base commit, the whole producer and all 5,875 private evidence
files; it also freshly audits all 250 primary XMLs. It verifies the prior actual
35-capture reader receipt instead of relaunching the same 35 Java inspections
for unchanged bytes. No original statistical computation is performed.

Public evidence contains source identities, already-public predecessor
metadata and counts. Raw command lines, runtime bindings, source-context
addresses, browser profiles and process/cleanup receipts stay private.

**Warnings and required actions:** a missing exact prerequisite exits3 and
skips the dependent operation. Obtain it through a permitted method, or retain
the skip if installation/access is forbidden. Exit2 admits no complete result:
preserve the attempt, resolve its stated integrity/input cause and retry new
output. Never refresh an old hash or silently substitute a historical edition.
