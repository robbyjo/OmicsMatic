# Synthetic Minimac admission fixture

These files contain no participant data. They are the frozen project-generated
24-reference-sample/six-target fixture with 120 biallelic variants. Thirty-one
target markers are typed; the other 89 give 534 held-out genotype cells.
`truth.vcf` records the explicit phased target calls.

`reference.m3vcf.gz` was generated by original Minimac3 2.0.1 with
`--noPhoneHome --processReference --rounds 5 --states 48 --cpus 1`.
Its 48 named haplotype columns correspond to two explicit copies of each of
the 24 diploid input samples. That fixture-specific relationship is not a
production sample-name inference rule.

`target.vcf.gz.csi` was created by the validated native `VcfCsiIndex` in
development candidate `8ca3828c57258ee7638c7796d47d04c37ef977d725d13a8e94ed013552212d2b`.
The compressed target bytes are immutable. Regenerate the index if those bytes
change; no external BCFtools runtime is needed for this index.

Every byte count and SHA-256 is pinned in `minimac-runtime-lock.json`. That lock
also pins the decoded original imputation records, including sample and variant
identities and all posterior fields, separately for each runtime profile.
Admission must reproduce those records and the known phased calls. Current
Minimac4 also compresses and exports the original reference, whose haplotypes
and AC/AN are independently expanded and checked.

Provenance and scope are recorded in `MINIMAC_SOURCE_REVIEW.md`,
`minimac-source-validation.json`, `MINIMAC_REFERENCE_AUDITS.md` and
`minimac-reference-validation.json` under `docs/literature/omics-2023-2026`.
These small synthetic tests establish runtime health; they do not establish
real-data accuracy or support mixed-ploidy reference preparation. The observed
original mixed-ploidy AN inconsistency and Savvy coordinate-query omissions
remain documented separately. Cell Ranger stays excluded.
