# Guarded MR-PRESSO native-family admission

This module reviews six source roles and replaces the one MR-PRESSO method-overlap
entry with a qualified native prepared-association workflow. It awards one native
family, no upstream family, no aliases and no added observations. The full250-paper
goal remains open. See [ADMISSION.md](ADMISSION.md) for lifecycle and required gates.

`primary.py` and the public six-role packet are frozen scientific/source evidence.
Do not edit them or refresh native-qualification hashes to force later verification.
`model.py` is a deterministic transition from the exact eight predecessor files.
`catalog.py` supplies plan/inspect/apply/current-verify with guarded replacements,
failed-write retention, rollback and concurrent-write preservation. The shared
Seurat transaction is reused with its own tests; it is not an OS atomic transaction
or protection against every possible filesystem race.

The native qualification has its own historical status with zero catalog credit.
The admission proof records the separate new credit and review ledger. Its current
guide is `docs/literature/MRPRESSO_WORKFLOWS.md`; the older native guide remains
byte-preserved inside the qualified source context. Original package editions,
seeds and simulation counts in the six papers remain unknown.

`compatibility.py` checks the successful saved pre-MR Squidpy catalog gate,
the exact two-route-line/one-help-line dispatcher extension, and22,895 preceding
JAR payloads with only the dispatcher changed. It does not rerun the older reader
in an incompatible current source context or change old expected hashes.
