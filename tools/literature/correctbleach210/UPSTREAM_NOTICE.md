# Original CorrectBleach and dependency provenance

CorrectBleach is maintained by Fiji developers; its original correction algorithms identify Kota Miura and Jens Rietdorf. This integration uses the complete original [2.1.0 source commit](https://github.com/fiji/CorrectBleach/tree/f3b48fc23cfbb06c3437b24519f7149dfc0e12f6), not an inferred paper edition. Original source files are unchanged. The release LICENSE, current source headers and POM state GPL version 3 or later; older README prose and comments state GPL version 2. Both statements remain in the exact source, without editing or claiming to resolve that historical difference.

The project native `CorrectBleachHistogram210` implementation derives its complete lookup and CDF behavior from original `histogram2.HistogramMatcher` and `histogram2.Util`. The original histogram source also retains its Springer book attribution. Original source and notices accompany the fixed source profile. Project controller, native port and observer additions are GPL-3.0-or-later under the project's license.

The declared original profile contains ImageJ 1.53t (public-domain statement retained from its official POM), SciJava Common 2.89.0 and Parsington 3.0.0 (their original BSD two-clause notices retained), and EventBus 1.4 (its original Michael Bushe copyright/Apache notice and Apache 2.0 license retained). Complete upstream source artifacts and POMs are required by the provider. The original published CorrectBleach JAR is used separately for independent controls; production providers compile the original source. No system Java runtime, complete Fiji distribution or biological research input is supplied by this component.
