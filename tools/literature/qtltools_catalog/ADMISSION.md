# QTLtools catalog admission protocol

This transition adds one upstream family from a method-overlap row and appends
nine individually reviewed QTLtools uses. It preserves all250 paper identities,
2722 observations,1630 older reviews,445 unrelated inventory rows and484 other
provider definitions. Native fdensity adds no duplicate family credit. Read
[the source crosswalk](../../../docs/literature/QTLTOOLS_CATALOG_INTEGRATION.md).

`close_qtltools_catalog.py --plan` requires NEW workspace build output,
`--primary-cache`, `--supplement-pdf` and `--checks-root`. It checks the exact
preceding Git metadata and841-member manifest, fresh250 XML/DOI identities and
the exact P190 supplement. It binds actual unchanged workflow/catalog owners,
compiled scientific source, current JAR, saved actual model qualification and
fresh Windows/Linux source audits. It also checks complete model/transaction and
actual source-refusal control archives and their current tested source hashes.
The plan writes exact-before metadata, qualification, registry and previews.
Canonical files remain untouched.

`--inspect --plan-dir PLAN` checks current source/controls and all preview bytes.
Supplying source arguments and checks root repeats those fresh checks. `--apply`
requires all of them, repeats inspection and preflights every target. The owned
transaction restores previous bytes after failure, retains failed new evidence
and preserves concurrent foreign edits. An existing admission owner is refused;
do not overwrite a failed owner to reuse its output path.

`--verify` checks the saved qualification receipts and entire control archives,
current tested sources, exact predecessor/after bytes, registry, embedded report,
full844-member manifest and review-only inverse. Both source arguments repeat a
fresh XML/PDF audit; an explicit checks root rechecks the actual immutable owners.
Saved readback runs no model. Original refitting remains explicit CLI REPLAY.
The current registry provider is `qtltools_catalog.model.registry`; frozen earlier
providers/readers stay on their exact owners or commits. Scientific source and
generic source-integrity rules are unchanged.

SKIP3: supply the named permitted missing dependency/source, including pypdf6.21.4
for the PDF audit, or retain the skipped dependent analysis. Downloads/private
installation are authorized where allowed. If installation is prohibited, state
the affected analysis and exact prerequisite. FAIL2: retain raw/null/partial/
failed evidence,resolve the named cause and retry NEW output. Never repair IDs,
nonfinite scientific results or unknown paper settings silently. Completed null
results carry warnings and are not positive findings.

Private source XML/PDFs, rendered pages, binaries/JARs, audit dependencies and
complete private/failed evidence need a separate checksummed handover. Both
unfinished reports remain off Pages, Cell Ranger remains excluded, and no
release,whole-tool,whole-paper or full-goal completion is claimed.
