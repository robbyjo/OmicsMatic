# Normal-build Enrichr qualification

From the repository root, with Python 3 and a NEW output directory:

```powershell
python -B tools/literature/verify_enrichr_current.py --out build/enrichr-current-readback-NEW
```

This performs saved evidence/source checks, no JVM or network execution. It
checks 42 tests on each of three JVMs, normal-build live/example receipts and
independently reconstructs all nine source result fields and TSV hits/terms
for 600 rows from the included raw synthetic-query replies. The entire
downloaded GMT libraries and complete live bundles remain private local
evidence. Service data/library terms remain separate from Java code licensing;
the earlier source/API checkpoint retains inspected license metadata.

The reader also checks every retained development-packet payload, the 25
original/annotated class pairs and the exact dispatcher/annotation source
transition to earlier ABF/API components. It does not run or modify historical
source readers, rewrite old hashes, overlay scientific source, reproduce an
author runtime or qualify historical client/library parity. Mutable handover
navigation is not a scientific-source fingerprint in this packet.

Read the [qualified workflow guide](../../vignettes/enrichr-current-service.md)
and [examples](../../../examples/enrichr-workflow/README.md). Catalog admission
is separate; this packet awards zero family credit by itself. SHA-256 checks
integrity against the saved records, not authorship or protection against
coordinated fabrication.
