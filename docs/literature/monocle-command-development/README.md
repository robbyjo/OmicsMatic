# Monocle source-build command integration

Read the [current command guide](../MONOCLE_COMMANDS.md) for copyable commands,
exact-edition choices, input contracts, runtime provisioning and prominent
SKIP3/FAIL2 recovery. The main source-build executable now exposes original
1.3.1 gene models, 1.3.3 prepared-graph learning, 1.3.7/Batchelor1.20 alignment
and trajectory inference, and Monocle2 2.26.0 differential testing. Existing
native ORDER and original 1.4.27 RUN actions remain available.

`VALIDATION.json` records actual original-package analyses, complete scientific
output comparisons with previous qualified runs, 565 focused tests, source and
package transitions, and real executable skip/refusal controls. Original source,
models, inputs, warnings and failed attempts remain retained. The first main-JAR
analysis exposed the standalone-only numerical-library guard; the new guard
verifies all 933 original JDistlib class entries in either supported packaging
and refuses class-path shadowing. Missing numerical libraries skip analysis.

`controls.zip` is an ordinary ZIP archive. `INDEX.json` records each captured
file's size and SHA-256. Every archive member was read back and matched to its
captured bytes. Expand it with ordinary ZIP tools into a **new** directory,
preserving the recorded relative paths. It contains complete saved synthetic
analysis outputs and source stages, plus selected build/test/process records
and current source snapshots. Large compiled JARs and installed R runtimes
remain separately provisioned dependencies with recorded identities; the archive
is not a complete runtime installation. File bytes are preserved; restored
filesystem permissions are not an execution attestation. See
`UPSTREAM_CREDITS.md` for original source licenses.

`P021_METHOD_DISCOVERY.json` identifies the custom regression-residual Moran
primitive that remains a native implementation target. Current author-source
inspection does not establish its executed paper commit or a complete historical
environment. That author source is not redistributed or executed.

This checkpoint improves source-build availability and fixes a real packaging
failure. It awards no new whole-Monocle family credit: the remaining paper roles
and complete 250-paper objective are still open. The released 0.4.0 JAR is unchanged.
