  rather than merely listing a URL. Exact per-cohort versions/settings remain
  unallocated; the separate PLINK 2 clumping/scoring role already existed.
- **P130 / PLINK 2:** the compound phrase naming PLINK 1.9 and 2.0 establishes
  release-2 postprocessing use. The later clumping stage explicitly names 1.9.

  family relationships with KING 1.4. It is not only a previous-cohort citation.
- **P229 / KING:** lowercase `king` names a current close-relative check with
  edition 1.4. Broad case-insensitive inspection also found eight mentions of
  people, institutions or historical rulers, which are explicitly excluded.
- **P114 / PLINK:** the XML Methods statement alone describes a CNV format.
  The exact [paper-linked Zenodo archive](https://zenodo.org/records/20802211)
  specifies executable PLINK 1.07 CNV filtering/map/count operations. Three
  source members and selected line hashes are checked without extracting or
  running scripts. The code distinguishes ignored PLINK P values from later
  inference; no PLINK association result is inferred from file format alone.

not establish support under current human autosomal hard-call contracts.
