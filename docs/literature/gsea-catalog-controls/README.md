# GSEA catalog admission controls

Twenty-eight controls pass on Windows/Linux Python. They exercise provider/edition
attribution, ambiguous and distinct source roles, old-review and unrelated-use
preservation, bad qualification/double-transition refusals, exact before archives,
owned writes/rollback, concurrent-edit preservation, output limits and the ban on
scientific-source compatibility inverses. The exact portable metadata fixture is
checked against the admitted predecessor; no scientific model or author script
is executed. checks.zip retains host logs, receipts and failed-write/foreign-edit
fixtures. CONTROLS.json binds the tested owner/source snapshots and every member.
