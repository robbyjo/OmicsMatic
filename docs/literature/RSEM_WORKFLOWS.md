# RSEM workflows

The local project now provides original RSEM alignment-mode expression fitting through `rsem-tools`, alongside native Java abundance and complete reference/alignment/model/result audits. The [runnable synthetic example](../../examples/rsem-workflow/README.md) includes setup, exact input preparation, fitting, capacity overrides and recovery steps.

**Missing or forbidden dependencies require a skipped analysis, exit 3. Invalid input, integrity, execution or capacity failures return exit 2.** Preserve `WARNINGS.md`, `analysis-status.json`, original stdout/stderr, ledgers and partial scientific files. Correct the named cause and retry to NEW paths. Existing outputs are preserved. Source setup requires `--allow-install`; network downloads additionally require `--allow-download`. The private cache must already exist and be canonical. Setup does not install a compiler.

Original execution requires Linux x86_64 Java; use Linux Java inside WSL on Windows. Supply the exact supported source edition, its observed build-receipt SHA-256 and declared library directories. Supported source profiles are 1.2.28, 1.3.0, 1.3.1, 1.3.2 and 1.3.3. Source identity determines the edition even when an original version message differs. Every fitting run verifies the installed source/build/payload and local host dependencies afresh; a receipt is not a portable admission ticket.

Supply a complete matching ordinary transcript reference prefix and the unmodified transcript-aligned SAM/BAM/CRAM. CRAM requires the exact explicit local uncompressed FASTA and adjacent `.fai`. Complete FASTA/index and header/reference checks precede decoding; URI and cache fallback are not admitted. Header versus effective-record length disagreements are retained and refused. The canonical SAM and expected parser files are audit artifacts; the original binary remains the fitting input.

Recipes explicitly declare read type, auxiliary tag including an intentional empty value, strand, seed, workers, posterior settings and applicable single-end fragment assumptions. A zero fragment-length standard deviation retains the original fixed-length model. Original low-quality seed behavior remains fixed at 25 bases. The native checks preserve all query groups, hits, read exports, transcript/gene identities, model/theta populations and output membership. Unknown fields, silently ignored settings and undeclared scientific outputs are refused. The command does not sort, repair mates, filter hits or impute qualities to make an invalid input pass.

Successful public fitting requires the root `COMPLETED.json` and `analysis-status.json`, plus their identified fitted-result record. Review root and fitting warnings, complete native audit records and all original logs. Numeric and structural checks do not certify convergence or study suitability. Historical zero-alignable-read failures remain failures for 1.2.28, 1.3.0 and 1.3.1; the newer zero-expression fallback is not substituted.

The [current proof](omics-2023-2026/rsem-workflow-validation.json) records 244 packaged tests on each JVM profile, strict Java 17/Javadoc, 12 actual public fitting cases including the documented source-setup example, 193 complete scientific files, 778 numeric cells, 10 runtime controls and 2 cache controls. Linux passes all 244 tests; each Windows profile passes 225 with 19 explicit Linux-only skips. The earlier [typed fitting proof](RSEM_TYPED_FITTING_VALIDATION.json) preserves 69 matched typed/direct cases, 2,136 scientific files across both sides, 4,624 numeric cells, six historical failures and five changed-result controls. Frozen source and failed attempts remain retained.

This integration covers supplied ordinary transcript references and original alignment-mode fitting. Genome/aligner reference preparation, allele-specific and pRSEM workflows remain outside this scope. No biological accuracy or whole-paper equivalence is inferred. New local work has not been pushed or released, and the full 250-paper implementation and semantic review remain active. Cell Ranger remains excluded; bcl2fastq analysis remains skipped under its separately documented unresolved requirements.
