# Saved SCENIC network development

This handover preserves **development evidence, not a qualified full SCENIC
adapter**. The separate native Java AUCell component is already qualified and
published. Read [the current next steps](../HANDOVER_SCENIC_NETWORK_2026-11-23.md)
and [machine-readable status](STATUS.json).

`evidence.zip` retains 37 files: both original synthetic probe attempts, exact
inputs/outputs, raw consoles, commands and source identities; four helper scripts;
and the unchanged five-paper source-role draft with the P153 missed-provider
candidate. `FILES.json` binds every decompressed member. All fixture expression,
TF, motif-annotation and ranking-database inputs were generated artificially by
the included helpers. No original full paper text, author data, installed runtime
or whole upstream source archive is included. Upstream algorithms were run from
their separately installed, unchanged original sources; those sources and license
notices remain available through the preceding component checkpoint.

From a checkout root, with Python 3:

```text
python -B tools/literature/verify_scenic_network_handover.py
```

The reader checks the saved record and explicit no-credit boundaries. It does
not refit GRN models, rerun motif pruning or scoring, inspect the current private
runtime, prove execution authenticity, or qualify whole-tool/paper/biological
validity. SHA-256 is integrity metadata, not a signature. Historical helpers have
fixed Windows/WSL paths and create new directories/branches; inspect and adapt
them to fresh paths before execution. Restore archive members under
`build/fu-1/build/scenic-2/` for the two probe directories, root `build/` for
`helpers/*`, and `build/fu-1/build/scenic-1/SOURCE-ROLES-DRAFT.json` for the draft.
Never overwrite the original captures.

**SKIP3:** supply the exact named permitted input/runtime or retain the dependent
analysis as skipped. **FAIL2:** no complete result is admitted; retain raw failed,
partial and undefined evidence, resolve its cause and retry new output paths.
The first probe's import failure remains alongside the successful module-launch
successor. GitHub is not a backup of private evidence or the WSL installation.
