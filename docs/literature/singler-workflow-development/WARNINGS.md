## Execution and model state

Use an explicitly permitted Linux/WSL runtime and original source profile.
Installation/download flags are explicit. Where a requirement is unavailable
or forbidden, SKIP3 skips dependent analysis and identifies what must be
provided. Analysis performs no installation or reference download. The
[workflow guide](../../../tools/literature/singler_workflows/README.md) provides
commands and trusted RDS constructors. References and labels must be supplied
explicitly; a current online reference is not an author snapshot.

Whole captured returns, conditions, calls, function bodies, environment contents
and reference topology are compared through version-3 serialization. No
environment or scientific field is discarded to obtain a comparison pass.
Saved training external pointers remain present as records but are not reusable
live native indexes. Classification uses the original live model in the same
process. Synthetic source controls establish no whole-tool validity, biological
accuracy or paper reproduction.
