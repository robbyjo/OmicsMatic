# Cell Ranger family: source review and user exclusion

**Implementation and runtime analysis are skipped at the user's explicit request on 2026-10-26.** No Cell Ranger, Cell Ranger ARC or Cell Ranger ATAC binary/runtime was downloaded, installed or executed. The user excluded this tool after reviewing its license. This is an exclusion from the implementation scope, not an implemented integration or a negative scientific result.

**Required action: none.** Leave the tool skipped unless the user explicitly reopens it. Do not register contact details, accept a license or install it automatically.

The frozen catalog retains 44 observed family roles. All 44 primary source identities and paragraph hashes, plus 26 supporting paragraph pointers, passed validation against the cached primary-paper XML. The primary pointers and the cohort are unchanged. This review distinguishes GEX, ARC, ATAC, mkfastq-only, reused cohort/resources and separate downstream tools. The registry still groups the name family under `cellranger`; it does not imply equivalent executables. Paper-wide semantic completeness remains open.

The official [source license](https://github.com/10XGenomics/cellranger/blob/cellranger-10.1.0/LICENSE) restricts internal use to the stated 10x product/data conditions and prohibits redistribution/sublicensing. The [official binary download](https://www.10xgenomics.com/support/software/cell-ranger/downloads) redirected to contact registration and license acceptance; no form was submitted. Do not transfer the separate FIMO nonprofit/research eligibility declaration to Cell Ranger.

Before the exclusion, a private checksummed Ubuntu 24.04.5 WSL2 distribution was installed successfully under `build/literature-review/cellranger-runtime/wsl-ubuntu-24.04.5`, named `JLinAlg-Omics-CellRanger-20261026`. It can support later Linux tools. No OS features, global WSL configuration, existing distribution or PATH were changed; there were no pre-existing distributions. The first imported distribution became WSL's default.

The WSL probe exposed about 32 GiB RAM. Its virtual filesystem reports more free space than the actual host volume, whose available storage was about 516 GiB. The vendor [full-analysis requirements](https://www.10xgenomics.com/support/software/cell-ranger/downloads/cr-system-requirements) specify 64 GB RAM and 1.5 TB free disk. These resource limits are recorded only; no full pipeline or small Cell Ranger test was run. The private Linux installation is not evidence that Cell Ranger is supported or available.

Reference/probe versions are not software versions. P040 reports literal `9.01`, which is not silently rewritten to a pinned `9.0.1`; P145's `v1.1.0_GRCh38-2024-A` is a probe-set label. P182 reports `GRCh38-1.2.0` while linking an archive ending `GRCh38-3.0.0`; the discrepancy is retained. P187 explicitly approximates Cell Ranger alignment with BWA-mem within WASP; that is not a Cell Ranger/WASP execution.
