# Eagle paper uses and implementation boundaries

All eleven Eagle observations have source-verified summaries. The primary article XML and exact paragraph hashes are checked by [the curator](eagle-source-validation.json); [machine-readable coverage](eagle-role-coverage.json) retains the reported editions and unresolved choices. The original 682 review objects remain unchanged. The catalog now has 693 reviewed uses and 202 supporting pointers; paper-wide semantic completeness remains open.

The current development command supports original Eagle 2.4.1 cohort/reference phasing with native VCF/BCF2.2 checks and conversion. It requires explicit inputs, map, assembly, region and policies. A reported 2.4.1 use does not supply the paper's unstated command or certify a study reconstruction. Older editions and local/remote server pipelines remain separate. Read [the workflow](EAGLE_WORKFLOWS.md), [BCF preservation rules](EAGLE_BCF_STATUS.md) and [validation](eagle-validation.json).

**Required action:** leave an analysis skipped when its requested edition or dependency cannot be supplied on a permitted host. The adapter reports **SKIP3** for unavailable dependencies/capabilities and **FAIL2** for invalid data, integrity, execution or capacity failures. Preserve failed/provisional bundles and follow their named recovery steps before rerunning to a new output. Require `COMPLETED.json` and its matching manifest/file hashes.

Source indexes are provenance only: a declared index is protected and hashed, never queried or certified against the BCF. Fresh prepared-input CSI files are generated and validated. Retain original binary/index snapshots, decoded text and conversion/matching ledgers. The separate generic HTSJDK version override is not certified as a lossless BCF2.2 converter; see the retained probes in the BCF guide.

Finch-or-Eagle ambiguity in P072, the supplementary workflow delegation in P092, historical 2.3/2.3.5 and coarsely reported 2.4/server editions remain explicit. Minimac, Beagle, GLIMPSE2, RFMix, genotype QC and downstream association are separate tools or steps. Validation does not measure biological phase accuracy, reproduce complete papers or establish every upstream option. Cell Ranger remains excluded.
