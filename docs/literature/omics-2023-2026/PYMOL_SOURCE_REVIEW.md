# PyMOL: source review and integration status

Twenty source roles and three additional supporting pointers are hash-checked. The registry groups the name PyMOL;this does not establish one edition,version or algorithm. The original open-source3.1.0 runtime was built and exercised privately. A validated development subset now runs through `pymol-tools`;see [the typed workflow guide](PYMOL_WORKFLOWS.md) and [validation record](pymol-adapter-validation.json). A separately validated [PDB2PQR/APBS/potential-surface workflow](POTENTIAL_SURFACE_WORKFLOWS.md) is now available. The remaining paper-specific/manual operations remain pending. Native distance/angle/torsion and supplied-pair proper rigid fitting are separately available in the validated development command described in [the guide](MOLECULAR_GEOMETRY_WORKFLOWS.md).

The [official open-source edition](https://github.com/schrodinger/pymol-open-source) has a permissive [license](https://github.com/schrodinger/pymol-open-source/blob/v3.1.0/LICENSE). Source tagv3.1.0 resolves to commit`f51e58f6b08308c41c85b9d12a23231f49ca325a`;the tagged source archive SHA256 is`54306d65060bd58ed8b3dab1a8af521aeb4fd417871f15f463ff05ccb4e121fe`. A private Ubuntu24.04.5/WSL2 build used NumPy1.26.4 and required the separate MIT-licensed MMTF-C++v1.1.0 headers. No original PyMOL source file changed. This local build is not an upstream binary release or a claim about every named paper edition.

The private runtime produced128 measurement cases,96 explicit-pair fits and headless cartoon/sticks/surface views of public [PDB1CRN](https://www.rcsb.org/structure/1CRN). PDB archive data are [CC0](https://www.wwpdb.org/about/usage-policies). Initial sticks were tightly cropped;an explicit5-Angstrom zoom buffer corrected all three views,which were inspected and checked for white margins. Those images validate rendering mechanics,not a protein model or a paper figure. The exact local wheel is now admitted by the public installer and typed command. It is a private validated build,not a publicly distributed upstream binary;missing/changed/forbidden dependencies skip analysis with explicit recovery.

Paper roles require separate operations: `align` and `super` establish correspondences/refinement;fixed-pair rigid fitting does not. APBS electrostatics needs its own solver,protonation/charges and grid. Manual bonds,rotamers and chi torsions require their actual selected conformations. P178 does not state whether each local RMSD window is refitted;P133 explicitly reverses the common confidence-colour ordering. P038 is a software-list use with no resolved operation. Preserve those uncertainties rather than inventing defaults.
