The complete paraphrases,scope caveats and seven family supporting pointers are
in `tools/literature/igv-use-reviews.json`. They distinguish upstream alignment,
RPGC/spike-in normalization,peak/variant calling and statistical inference from
viewer display and manual inspection. In particular,P086uses SEG copy-number
views;P214uses methylation-containing HiFi BAMs and independent human QC;
P217reports allele depths at a linked coding SNV,while the upstream c.−69 base
is outside the RNA sequence. A generic pileup with unspecified filtering or
overlapping-mate treatment is not an established reconstruction of those counts.
P195does not assign an exact contact-file format or panel to IGV among its
listed visualization tools. P163's underscore2.4.15 is an explicit version;
P013's99 and P109's73 are citations. Neighboring upstream versions are not IGV
versions. No track scale,color palette,missing-data rule or display filter is
invented when it is unstated.

The extractor still defaults to Methods/analysis evidence. A Results paragraph
can be admitted only for the exact named tool and paragraph hash chosen by a
human review. Other tools in that paragraph are not thereby admitted. Unreviewed
Results,availability statements,reference-only mentions and immunoglobulin
IGV homonyms remain excluded by the checked cases. All40extractor regressions
and2selection-history regressions pass. All250XML identities,2425primary tool
pointers,604reviewed summaries and127supporting pointers pass the source audit.

**IMPLEMENTATION REMAINS IN PROGRESS.** IGV is still marked missing in the
implementation queue. The current development JAR has no validated IGV project
command. Original runtime feasibility probes are separate evidence,not an
adapter badge or a reconstructed paper analysis. See
[IGV_RUNTIME_STATUS.md](IGV_RUNTIME_STATUS.md) and
[igv-source-review-validation.json](igv-source-review-validation.json).

Reproduce the source checks using the frozen XML cache:

```powershell
python tools/literature/curate_igv_uses.py --out NEW_REPORT_DIRECTORY
python tools/literature/audit_catalog.py
```

Do not overwrite earlier reports or rerun `--apply` to replace reviews. The
curator rejects a different existing review. Whole-paper semantic completeness,
original-runtime integration and published-version reconstruction remain open.
