## Observed original behavior and required actions

- **Marker IDs and empty success:** with PLINK input, group and conditional markers match exact BIM IDs. The official coordinate-name example returned exit0 with an empty gene file; conditional execution rejected absent markers. An explicit coordinate/allele-to-BIM-ID ledger recovered the controlled runs. Required action: verify every marker identity and every requested group. Resolve coordinate/allele mappings explicitly and unambiguously; never guess allele/strand identity. An empty exit0 output is not a completed gene analysis. Empty masks/groups need named retained status.
- **Missing-call semantics and QC:** the original `minor` option fills minor-allele dosage0, meaning major-allele homozygotes. Single-marker QC first checks pre-imputation missingness/frequency/MAC, then checks MAF/MAC again after imputation and cleanup; gene QC and masks use post-imputation values. The earlier pre-imputation-only description was incomplete. Inclusive dosage cleanup can alter small mean-imputed hard calls and is now explicitly declared and audited. At a threshold, original `ref-first` subtraction can turn an exact observedMAC20 into a computed value below20. Required action: declare the original imputation policy and allele order, retain exact observed counts and original floating QC values, and review every boundary exclusion. Do not silently add a tolerance or change the threshold.
- **Self-conditioning:** the target `rs79`, also supplied as a conditioning marker, produced `SE_c=-nan`, near-zero conditional variance and printed conditionalP1. Required action: mark its conditional estimate unreportable or explicitly exclude conditioning markers from the target list with a retained ledger. Do not report a zero effect or interpret printedP1 as an estimable null result.
- **Sparse-GRM coverage:** in the controlled1,000-sample fixture, screening with100 random markers omitted1,549 pairs with independently computed full-GRM values above0.12501. All5,122 stored coefficients matched the independent calculation, with maximum difference7.47e-7 between float64 and original float arithmetic. This count describes this fixture. Required action: assess pair coverage independently before asserting a complete graph for unrelated-sample selection; do not infer completeness from a SAIGE sparse-GRM file. Preserve the screening settings and cohort/marker identities.
- **Ultra-rare collapse:** original gene-test MAC accounting uses the maximum minor dosage per participant across ultra-rare variants. A homozygous dosage2 remains2. Required action: preserve ordered rare/ultra-rare memberships and the collapsed case/control counts; do not replace this operation with a binary carrier indicator or sum overlapping ultra-rare calls.

## Independent reference evidence

Six authentic original runs cover both allele orders and all3 missing methods on derived inputs with three deliberately missing variants and one inverted major-effect variant. Native calculations match189 variant rows,1,134 exact case/control genotype counts and945 rounded AC/AF/missingness values. Each alt-first run has32 eligible rows; each ref-first run has31 because the source floating-point QC boundary is reproduced explicitly.

The gene reference has8 eligible mask rows,40 exact MAC/membership counts,24 bounded componentP values and6 independently recomputed Cauchy combinations. Four masks have no eligible variants and remain explicit. The LD reference has70 marker rows,210 exact metadata fields and1,260 independently recomputed lower-triangle genotype cross-products, including implicit zero entries. One LD group is empty. These are unweighted minor-dosage `G'G` cross-products, not centered/standardized LD correlations.

The quantitative sparse-GRM reference independently verifies raw rank-normal transformation and32 score statistics. The full-GRM binary reference fits22 LOCO models and independently verifies32 chromosome1 score statistics. The categorical variance-ratio fixture has two MAC bins. Source GLMM fitting, sparse-PCG variance, SPA, Firth, SKAT-O/SKAT and burden test distributions remain delegated to the original runtime; checking counts and Cauchy aggregation does not reimplement those algorithms.

The conditional reference independently checks32 primary projected scores and63 normal-P intervals derived from printed-statistic precision. It retains31 finite original conditional estimates and one explicitly unreportable self-conditioned target. Conditional covariance/Schur-complement and effect estimation remain original computations.
