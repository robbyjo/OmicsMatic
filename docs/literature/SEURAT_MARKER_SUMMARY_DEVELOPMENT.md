# Native Seurat marker-summary development

`org.jlinalg.sequence.SeuratMarkerSummary` computes sparse fold-change summaries and the filtering/correction/ordering around marker tests. It provides explicit source profiles for Seurat 4.1.0, 4.3.0, 5.0.0, 5.1.0, 5.2.1 and 5.6.0. This is a development API for the Signac differential-accessibility integration; **Signac remains missing and Seurat remains method-overlap in the catalog**. The credited total remains 70 new scoped integrations, 73 including existing adapters, with 258 named tools missing.

**No Wilcoxon, logistic or other hypothesis test is implemented by this API.** `finish` accepts supplied p values and applies the source's correction and ordering. Those supplied probabilities are inputs, not validated inference or evidence of biological significance. A full typed original-runtime analysis/capture interface remains required. Independent original Wilcoxon/LR controls have been prepared separately; they are not Java adapter admission.

## Source differences retained

Seurat 4.1.0 adds the pseudocount to the group mean and applies `expm1` for the data slot. In 4.3.0, data-slot `expm1` requires recorded `LogNormalize`; missing/other normalization uses arithmetic values. The v5 profiles add the pseudocount to the **group sum before division by group size**. Thus unequal group sizes can affect even an all-zero row when pseudocounts are positive. A recorded non-LogNormalize method also selects the count-mean branch for the v5 scale-data option. These are retained source behaviors, not inferred corrections.

Detection fractions use `value > 0`, including the effect of implicit sparse zeros, then original R rounding to three digits before filtering. The rounding helper specializes R's `fround` distance/ties-to-even rule; plain integer rounding of `1000*x` can differ. Its source reference is R Core's [fround implementation](https://github.com/wch/r-source/blob/R-4-6-branch/src/nmath/fround.c), Copyright Ross Ihaka 1998 and R Core Team 2000–2020, GPL-2.0-or-later; this project's code is GPL-3.0-or-later.

Prefilters use the rounded maximum detection fraction and between-group detection difference, followed by the fold-change criterion unless the explicitly selected **matrix-level testing slot** is `scale.data`. This testing slot is separate from the slot used for fold summaries. Whole `FindMarkers.Assay` dispatch can consume slots differently; this API does not infer or reconstruct its dispatch. Feature filtering occurs before upstream cell downsampling. Sampling and statistical fitting remain separate.

After supplied p values, correction is Bonferroni over **all original assay features**, not only tested/selected rows. v4's secondary ordering key repeats the p-value column, so equal-p rows retain their incoming order. Version 5.0.0 uses absolute fold change; 5.1.0 onward uses the absolute detection-fraction difference. `only.pos` removes nonpositive effects after testing, independently of the earlier threshold filter.

## API and example

The immutable finite-real CSC matrix retains exact feature/cell IDs and explicit zero entries. Cell indices are zero-based, unique, disjoint and explicit; no donor aggregation or biological-replicate inference occurs. Summary work and memory scale with features, cells and stored values rather than their dense cross-product. The constructor validates/copies the input before the calculation's work limit; callers must also bound intake/heap appropriately.

`Options` selects the source profile, summary slot, normalization provenance, pseudocount and log base. `summarize` returns every feature's fold change and rounded detection fractions. `prefilter` requires explicit thresholds and the matrix-level testing slot. `finish` requires unique exact summary records, supplied probabilities/NaN and the post-test positive-only choice. It does not authenticate inputs or execute a test. The Java scalar API has a NaN value and does not encode the distinction between R's NA and NaN; a future transport interface must preserve that distinction separately.

The [copyable synthetic example](../../examples/seurat-marker-summary/README.md) demonstrates the current raw-count summary without R or invented p values. The development JAR is built into a separate directory; canonical/released JARs and main command dispatch are unchanged.

## Validation and unfinished work

The [original fixture receipt](../../src/test/resources/org/jlinalg/sequence/seurat-marker-summary/CAPTURE.json) retains 162 original six-edition summaries and controlled pre/postprocessing calls, plus 2,638 exact R detection-rounding comparisons. A declared fixed-p callback isolates filtering, correction and ordering in these controls: it is **not a Wilcoxon/LR test implementation**. All 162 summaries and feature selections agree; 156 postprocessing outputs agree, while six missing-identity outcomes are explicit native refusals. Tolerances for finite fold summaries are absolute/relative 3e-12; detection rounding, identities, selection and order are exact. Nonfinite outcomes remain explicit.

All 165 tests pass in normal Gradle and against the actual normal-Gradle development JAR on Windows Java 21/25 and Linux Java 21. Every prior JAR member is unchanged; only this API's new classes are added. Read-only source admission compares all 42 top-level differential-expression function bodies/formals in the installed current Seurat namespace with the retained official 5.6.0 file. It does not authenticate installed native DLLs or the whole host.

Separately, six current original statistical controls completed: pairwise Wilcoxon, pairwise LR, LR with numeric/factor covariates, counts-slot Wilcoxon, all-group positive Wilcoxon and all-group LR with depth adjustment. Their source warnings and complete outputs are retained, including the earlier missing-Matrix-coercion setup failure. The earlier regular TSV transport could not distinguish NA from NaN or retain full finite precision; it is retained as superseded. The current reference uses explicit NA/NaN/Inf kinds, 17-digit finite text and original RDS captures; use this corrected reference for future adapter comparisons. A separate formatter probe exercises the distinct nonfinite kinds even though these six statistical tables contain no NaN token. All 27,958 inventoried files in the four pre-existing R libraries remain unchanged. Actual R execution was Windows-only.

The typed original-runtime request, output admission, failed/dependency-skip capture and recovery gates still need implementation. Full Signac additionally needs its remaining wrapper/plotting/public-workflow and paper-review gates, including a newly located P134 Results use. Historical whole-package environments, biological validity, full-paper reproduction, a release, GitHub push and deployment are not claimed. Cell Ranger remains excluded; the full 250-paper goal remains active.
