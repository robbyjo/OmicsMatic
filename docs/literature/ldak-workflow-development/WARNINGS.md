# LDAK warnings and required actions

**No complete LDAK workflow adapter or paper analysis is admitted here.** This
checkpoint provides a native Java kinship kernel, its source-specific BED reader,
original runtime preparation, and original-software development controls.

**Observed upstream substitutions must remain visible.** On the official
3,289-variant tutorial, original LDAK 5.2 SumHer reported that it replaced **18
zero test statistics with `1e-6`** and **four tagging values below one with one**.
These are original program behaviors. They do not mean that the literal input
values were used throughout fitting. Input files and original consoles are
retained, and the Java kinship method does not perform these SumHer substitutions.
Review [the exact messages](ORIGINAL-DIAGNOSTICS.json) and original input values.
The future captured adapter must expose these transformations and their counts
before any paper-specific analysis receives credit.

The original tutorial also warned about strong-effect loci and its small
predictor count. Choose QC and cutoff rules from the actual analysis specification;
do not silently apply `--cutoff 0.01`, drop predictors, suppress warnings or use
the tutorial's heritability estimates as a real-study result. The eight small
kinship fixtures produced original warnings for constant/all-missing predictors;
the native kernel retains explicit dispositions for these omissions.

| Condition | Required action |
|---|---|
| Missing/forbidden original runtime, Linux execution or download | SKIP3: skip dependent original-tool analysis. Use a permitted Linux x86_64/WSL environment and the exact archive or explicitly permitted download. Native Java kinship needs no original runtime. |
| Wrong archive, invalid metadata, exceeded capacity or recording failure | FAIL2: admit no prepared runtime or complete analysis. Retain partials and the error record, resolve the named discrepancy and retry a new output path. Never refresh pins or truncate input to get a pass. |
| FAM sex contains `NA` | The LDAK-specific reader preserves the token as unused metadata. Do not rewrite the original FAM to satisfy the general PLINK reader. The initial general-reader refusal remains retained. |
| Unknown paper binary, model, reference or alpha grid | Record the unknown setting. Supply explicit justified inputs before a study run; a selected 5.2 runtime or arbitrary grid does not recover the authors' environment. |

Runtime preparation performs only an intentional usage probe. Its original exit
one is expected; require helper exit zero and its completion receipt. This is
separate from successful scientific execution, convergence, captured verification
or genuine replay. No new family integration credit or global catalog update is
made at this checkpoint. Released v0.4.0 lacks the new native classes.
