# HOPS0.35 original postprocessing checkpoint

Read the [copyable setup/run/verification guide](../HOPS_POSTPROCESSING.md) and
[warnings and required actions](WARNINGS.md) first.

This source-bound stage fills the original AMPS plotting/workspace operation
after verified MaltExtract extraction. It preserves every enabled original
output and compares complete RData statistics, class matrices, TSV and optional
JSON with native Java. It does not run MALT or qualify whole HOPS. The canonical
executable and command dispatcher are unchanged; additional tool-count credit is0.

The JDK21/JDK25-built development JARs target Java17 bytecode. Original processing
and fresh RData verification are qualified on native Linux x86_64 JDK21. JDK25
builders and native unit tests are covered; Linux JDK25 execution is untested.
The complete minimal source dependency closure compiles with `-Xlint:all -Werror`.
Full-project regression was not rerun against unrelated unfinished study work.

Evidence includes three successful complete workflows with22 sample–taxon pairs,
308 node/numeric fields, both JSON choices, a10001-read control, a hyphenated
sample name, nine rehashed contradiction refusals, two complete public R installs,
four missing-dependency/capacity/retention controls, and an installer-group timeout
control. All31 focused/adjacent tests pass on Windows JDK21 and25. The frozen
native oracle separately covers2901 statistic pairs,420 class boundaries and
seven refusals. Three independent original RData productions agree.

`controls.zip.xz` contains a deduplicated complete logical evidence population,
including full captured extraction bundles, original outputs/workspaces and
process records. No partial row sets replace complete inputs. Upstream programs,
installed R/JRE trees, package archives, eager images and GATK binaries are not
bundled. Provider metadata and exact public package locks support separate
permitted installation. The original GPL postprocessing source and unchanged
workspace functions/output retain upstream attribution and license notices.

`VALIDATION.json` records source/archive identities and exact qualification scope.
`PACKAGED_APPLICATION_IDENTITY.json` proves that final candidates preserve every
program/resource payload member from the producing candidates. Container dates
may differ. Public saved replay rebuilds the application, restores all logical
evidence, checks native original controls, freshly decodes all three successful
workspaces and rejects the nine altered bundles. It repeats no fitting/plotting.

The first negative-fixture set omitted the nested extraction completion marker,
so eight cases stopped at the inventory gate. Its nine-semantic-refusal claim
and the first two public replay claims are explicitly invalidated and retained
under `invalidated-attempts/v1`. The corrected qualification preserves that
marker and requires each intended diagnostic; corrupt RData must reach and fail
fresh original decoding. A subsequent incorrect expected-diagnostic fixture is
also retained. Generic integrity failures cannot satisfy the semantic checks.

Original `default` and empty-candidate R failures remain unreportable as results.
The initial provider-link admission failure and an invalidated policy-test
fixture are retained separately. Their diagnostics are not rewritten as success.
SHA256 records integrity, not distributor signatures or producer authenticity.
