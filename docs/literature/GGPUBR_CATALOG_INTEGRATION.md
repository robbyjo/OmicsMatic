## Warnings and required actions

- **SKIP3 skips dependent analysis** when the exact source, private runtime/provider, input, literal export/package, permitted download/install or execution is missing or forbidden. Install only where permitted, supply the named prerequisites and retry NEW paths. Use the qualified Linux/WSL R4.3.3 profile, original ggplot2 3.4.3 and rstatix0.7.2. Keep providers in persistent permitted directories and select the literal ggpubr edition. A READY provider is not an analysis result.
- **FAIL2 admits no complete result.** Keep every input, full original object/layer/table/plot, error/warning, raw process log, partial file, inventory and status. Correct the named cause and retry NEW paths. Exit0 from a renderer does not override a failed statistical layer, incomplete population or missing output.
- **Review all original warnings.** Known `Computation failed in ...` warnings refuse admission. Ordinary warnings remain visible; original `warn=2` remains an error. Silent empty statistical layers need explicit caller eligibility and expected-row checks. Unknown condition totals from interrupted worker diagnostics are unavailable, not zero; the raw record and recovery report are retained.
- **Supply the scientific choices.** Plot coloring alone does not define a group mapping for `stat_cor`. Pairing order, variance assumptions, direction, adjustment families, missing/nonfinite-value handling, complete populations and label positions remain explicit caller decisions. Generic package listings do not identify an exact operation. Unsupported editions are not silently substituted.
- **Trusted code requires explicit ALLOW policies.** Scripts run with account permissions. The controller supervises the owned process group and workspace limits; it is not an OS sandbox or total CPU/RSS containment guarantee, and separately created process sessions are outside that boundary. No author-runtime, whole-paper or biological reproduction follows from file/marker admission.

Read the [workflow, provider installation and complete example guide](GGPUBR_WORKFLOW_DEVELOPMENT.md) for copyable commands. Native Windows original execution skips. Cell Ranger and Cell Ranger ARC remain excluded by user request. Existing rstatix, QuPath, AllelicSeries, palette, ImageJ and other tool limitations remain in their retained guides and current warning pages.
