# Warnings and required actions

**Require exit 0, COMPLETED.json and analysis.json result_admitted=true.** Read
the run's WARNINGS.md and any NUMERIC-WARNING.txt. Preserve original captures,
partial/failed results and the qualified executable/checksum. A table alone or
an unadmitted report is not a complete comparison family.

**SKIP3:** required accessible/permitted input is unavailable, or the requested
design is explicitly paired/repeated/nested/mixed. Skip the dependent analysis;
supply the input/access or a separately qualified implementation of the named
design. Retry new output. No external runtime install is needed for native
Dunn. Optional R/rlang source comparisons need those permitted dependencies;
if unavailable, skip that comparison and retain the specific warning/action.

**FAIL2:** preserve inputs/partial output and read FAILURE.txt. Resolve its
named formatting, all-tied variance, duplicate/self/unknown hypothesis,
capacity or integrity cause; retry new output. Never drop rows/groups, repair
labels or replace nonfinite values to force admission. Existing output is
preserved. Broken console/output recording cannot publish a completion marker.

**Model/family:** independent-sample pooled-midrank normal approximation with
ties and no continuity correction. Small-sample probabilities are approximate.
This is not pairwise Mann–Whitney, a general median test, repeated-measures Dunn
or Dunnett. All declared groups determine ranks, including unselected groups;
only the declared comparisons determine correction. No omnibus significance
filter or cross-outcome correction is implicit. Declare the actual biological
observational unit and all intended groups/comparisons.

**Probabilities:** numeric zero can be floating-point underflow. Retain z and
finite log probabilities. Read NUMERIC-WARNING.txt; do not treat numeric zero
as exactly zero mathematical probability. A literal -Inf log explicitly records
an unrepresentable log tail. Dependence assumptions differ across multiplicity
methods; no software-name mention selects an appropriate correction.

**Unqualified source behavior:** original dunn.test 1.4.2 has retained
noncumulative stepwise differences, Šidák cancellation and two-group method
errors. Native standard corrections use independent references; original code
and failed results remain unchanged. No whole-package or licensed Prism
runtime parity is claimed. Paper inputs/settings and the outer correction
families remain unresolved where the source does not provide them.

The source review records the omission and five verified pointers; canonical
