# Monocle, Cicero and py-monocle: source-use review

The unchanged 250-paper cohort now has **389 distinct named tools, 2,449 paper–tool observations, 917 reviewed uses and 309 supporting paragraph pointers**. This update preserves all 905 prior reviews and adds nine Monocle reviews plus three previously unregistered Cicero/py-monocle observations. Every source XML hash, DOI, published primary pointer and reviewed summary/support pointer is checked. Paper-wide semantic completeness remains open; a named mention is not automatically evidence that software was executed.

**Implementation count remains 74 new scoped integrations: 16 native Java and 58 upstream adapters.** Monocle remains missing at the full reviewed-role level, with separately validated development workflows available. Cicero and py-monocle are separately missing tools, bringing the catalog's missing count to 256. The canonical executable is unchanged. Cell Ranger remains excluded at the user's request. No new release or website deployment is part of this update.

## Available development workflows and recovery

The [native/Monocle3 root guide](MONOCLE_TOOLS_DEVELOPMENT.md) distinguishes Java prepared-graph ordering from original Monocle3 1.4.27 raw-count trajectory learning, gene GLMs and stock Moran tests. The [Monocle2 guide](MONOCLE2_DIFFERENTIAL_DEVELOPMENT.md) describes the separate 2.26.0 differential-testing adapter. Those are validated, bounded workflows, not every operation in this table or the papers' complete historical environments.

**SKIP3:** missing, forbidden, unsupported or mismatched exact runtime/dependencies skip the dependent analysis. Monocle2 requires Linux Java and the declared R4.2.1/private dependency profile, including a separate original HSMMSingleCell1.18.0 library. On Windows, invoke Linux Java through WSL with Linux paths. Analysis installs nothing. Provision only where permitted; otherwise retain the skip. Do not silently substitute versions, generations, formulas or scientific input units.

**FAIL2:** any original failed gene, error, timeout, capacity breach or audit mismatch rejects the entire atomic batch. Original failed-gene p/q=1 values remain failures, not valid null findings. Free-NB and binary/proportion `binomialff` controls fail in the original Monocle2 helper under the selected VGAM profile. Preserve original objects, warnings and transcripts, correct the named cause, and retry new paths. Do not drop genes, impute values, repair IDs or replace nonfinite results to force success.

The first attempt retained complete scientific outputs but failed its own save/reload assertion by using a Monocle2 accessor on a Monocle3 object; a fresh corrected control passes.
