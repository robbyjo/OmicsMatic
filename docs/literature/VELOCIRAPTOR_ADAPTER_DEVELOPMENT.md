## Why the dependency profiles remain separate

The original scvelo 0.3.3 pseudotime code calls `scipy.sparse.linalg.eigsh` without supplying an eigensolver RNG. The installed SciPy 1.18.1 source initializes that RNG with `numpy.random.default_rng(None)`. SciPy documents that this default uses operating-system entropy; the `rng` interface was introduced in 1.17.0 alongside the ARPACK rewrite. Seeding the legacy NumPy RNG does not seed this separate generator. These sources provide a supported explanation for the observed within-original variability; the complete failed comparisons and both original returns remain retained. See [the official eigsh documentation](https://docs.scipy.org/doc/scipy/reference/generated/scipy.sparse.linalg.eigsh.html) and [SciPy 1.17 release notes](https://docs.scipy.org/doc/scipy/release/1.17.0-notes.html).

The separate explicit SciPy 1.16.3 profile retains the original legacy-ARPACK implementation. It changes no velociraptor or scvelo algorithm, and does not establish universal bit reproducibility. Its new two-mode complete reference comparisons passed; broader adapter qualification remains unfinished. Earlier profiles remain available as historical evidence; saved manifests and hashes have not been refreshed to hide their differences.

Earlier independent setup failures are also retained. The unconstrained upstream installation imported successfully but failed during real numerical work with NumPy 2.5/Pandas 3. The original Gillespie fixture contains a zero-library cell and fails automatic R size factors; an explicit unit-factor control encounters an original read-only-array failure. No cell was dropped and no pseudocount or factor was silently added. The first adapter request mistakenly required BiocSingular 2.6.0 instead of the installed 1.26.1 and skipped before analysis. A later request hit Python's Unix-socket path-length limit. Another run exposed the controller's mistaken rejection/copying of normal multiprocessing sockets. Each current request uses a short private native Linux temporary root, and a normally exiting worker first preserves its available R session tree. The controller copies every available regular file and retains literal link/socket/FIFO metadata without following links or reading IPC streams. Original native roots remain retained. Live IPC state and terminated process memory are not serialized or reconstructed.
