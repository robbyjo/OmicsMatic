# Historical TwoSampleMR execution evidence

Read the [checkpoint](../TWOSAMPLEMR_HISTORICAL_CHECKPOINT_2026-11-21.md),
[guide](../TWOSAMPLEMR_HISTORICAL_WORKFLOWS.md) and
[examples](../../../examples/twosamplemr-historical/README.md) first.

`PROFILE.json` pins the unchanged normal-producer source inputs,27 canonical
files, new validation helpers and examples. `INVENTORY.json` maps each retained
logical file to a content-addressed blob in `evidence.zip`. Commands, direct RDS
returns/errors, RNG, typed exports, failures, actual replays/examples, Linux
R-free verification and protection checks are retained. Prior build/source
provenance is included with its original dates and is not a fresh build.

`OMITTED.json` records generated or private exclusions. The deliberately mutated
negative-control package source/library is private; only its mutation declaration,
installation logs and checksums are public. Runtime binaries, old source/startup
configuration, the producer JAR and full primary text require a separate
checksummed transfer using the preceding handover census and this packet's
preservation receipts. GitHub is not a full machine backup.

The saved reader validates identities, archive contents and declared evidence.
It does not rerun scientific analyses, establish whole-tool/paper parity, or
turn SHA256 into a signature. Original R execution is Windows4.6.1 only;
Linux qualification here verifies saved captures with Java. Historical clumping,
provider/source review, global registration and catalog admission remain open.
The full goal is unfinished and no new catalog credit is granted.
