# Sources and reuse boundaries

- ISAC's FCS3.1 Normative Reference, copyright 2008–2009 ISAC, is distributed
  unmodified under its stated CC BY-SA 3.0 Unported terms. Its authors and
  copyright/license notice remain in the document. The source copy came from
  the [George Washington University cytometry site](https://flowcytometry.gwu.edu/sites/g/files/zaskib311/files/2021-11/Data%20File%20Standard%20for%20Flow%20Cytometry%281%29.pdf).
  See the [ISAC standards page](https://isac-net.org/data-standards/) and
  [license](https://creativecommons.org/licenses/by-sa/3.0/).
- Original FlowIO1.4.0, Scott White, BSD-3-Clause, supplies an independent stored
  value reference. Source commit `9ae65421cbe64d3ff17eeaf81f9dd0fbb9079436`,
  exact PyPI source archive and original `LICENSE` are retained. The original
  source was imported unchanged for the development comparisons. The reference
  uses its recorded NumPy/Python environment; none is required by the native API.
- Original vendor/control FCS files come from the pinned FlowIO repository.
  Complete original bytes remain privately retained and individually identified
  by the public reference lock. They are not redistributed in this control ZIP;
  the code's BSD notice does not establish separate rights for all source data.
- The new Java implementation and independent Python-struct storage fixtures
  are project code under GPL-3.0-or-later. The GPL text is retained separately.
  JUnit Platform Console Standalone1.13.4, with its official checksum already
  verified, is the test-only Linux runner and is not bundled here.
- Primary paper XML identities and paragraph pointers support the frozen
  cytometry name census. Whole articles and proprietary vendor applications
  or workspaces are not redistributed. No vendor equivalence or biological
  validation is inferred from a storage-reader comparison.
