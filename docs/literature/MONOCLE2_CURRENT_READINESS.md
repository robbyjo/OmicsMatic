# Monocle2 differential-testing readiness checkpoint

**No Monocle2 user analysis is admitted by this checkpoint.** It records successful original-source controls before a Java Monocle2 adapter is implemented. The root `monocle-tools` interface at this checkpoint exposes native Monocle3 prepared-graph `ORDER` and original Monocle3 `RUN`; neither substitutes for Monocle2 `differentialGeneTest`. Paper P099 names Monocle2 differential testing with expression/FDR/fold-change filters and additional age/AD/sex roles. Its exact patch, family and complete model formula remain unreported. A TPM filtering threshold does not establish eligibility to treat TPM as raw counts.

The official [Bioconductor package page](https://bioconductor.org/packages/3.23/bioc/html/monocle.html) identifies the 3.23 package as `monocle` 2.40.0 under Artistic-2.0. The exact source archive, repository record/MD5, SHA-256 inventory, headers and all 161 source files are captured in `build/literature-review/monocle-runtime/monocle2-source-intake-1`. This is a declared current reference candidate, not evidence of the paper's unspecified historical patch.

Source inspection shows that `differentialGeneTest` fits full/reduced VGAM models and compares them with a likelihood-ratio test. Its negative-binomial path can divide expression by size factors and round the response; a fitted dispersion function can determine a gene-specific size parameter. This differs from Monocle3's offset-based model worker. The original final BH adjustment uses only rows with status `OK`; failed source rows retain `FAIL` with p/q values of 1. A future adapter must preserve those failure statuses and must not report them as valid null findings.

No configured differential test completed. The exact original error, source, input/CDS objects, transcripts and library before/after hashes are retained. No original function was patched, no genes were dropped and no substitute Monocle3 test was run.

**SKIP3 — the attempted older dependency profile is unavailable under R 4.6.1.** `monocle2-dplyr-intake-1` captures the unmodified official CRAN dplyr 1.1.4 archive and an explicit compatibility override. `monocle2-reference-setup-4` attempted it only in another NEW private library. The setup records its nonzero install status and exact-version failure; all dependent analyses remain skipped. Existing dplyr and shared runtimes were not changed. This is not permission to patch upstream C/R code or silently claim a compatible/historical environment.

**Required action:** preserve these attempts and provision a separately declared compatible older R/dependency profile only where installation is permitted. If provision is forbidden or fails, skip dependent Monocle2 analyses and retain explicit warnings/errors. ## Completed original scientific controls

`monocle2-source-intake-2` retains the exact original 2.26.0 source, repository record and 161-file byte inventory. Before fitting, `monocle2-legacy-readiness-probe-6` compares selected loaded R bodies/formals against that source: constructor, differential helper/test, model comparison, size-factor estimator, dispersion estimator, matrix-apply helper and dispersion hint. All eight checks passed. This is selected R-source/namespace verification, not complete native-DLL source authentication.

The probe constructs seeded synthetic **120 genes by 200 cells**, preserves literal axes, estimates original size factors and dispersions, and runs three original negative-binomial-size differential cases:

* `~condition+progress+sex` versus `~progress+sex`, with relative expression enabled;
* the same nested models with relative expression disabled;
* `~sm.ns(progress, df=3)+batch` versus `~batch`, with relative expression enabled.

Each returned 120 rows in exact gene order with original status `OK`: **360 original differential tests**. Original CDS objects, fitted dispersion data/functions, complete test tables, arguments, seed, transcripts and session information remain retained. A separately rebound original single-gene helper agreed with the complete test's first-gene p-value in each case. A corrected metadata-only rerun preserved every complete test table identically.

`monocle2-readiness-audit-1` confirms finite p/q values in `[0,1]` and recomputes BH independently in Python from 17-digit exports of complete original RDS values. It also checks the exact original source guards, metadata boolean and unchanged complete rerun tables. Full Linux `lstat`/symlink/regular-file inventories verify **34,145 candidate runtime files and links unchanged**, and the separate data library is checked before/after. Reuse of a prior completed inventory is explicit, pinned and followed by a complete post-run comparison; the scope is not reduced to selected numerical files.

**Prominent retained compatibility warnings:** Matrix, Biobase, ggplot2, VGAM, DDRTree and irlba report that they were built under R 4.2.3 while this reference uses R 4.2.1. Original dispersion estimation also emits `group_by_()` and `select_()` deprecation warnings under dplyr 1.1.4. The complete controls passed with these warnings; this does not establish arbitrary workflow compatibility. Read the selected probe's `WARNINGS.md`, `RESULT.json` and transcripts. No source warning was suppressed by patching the original software.

Earlier legacy attempts remain retained: the first inventory stopped on Windows' inability to stat Linux symlinks; the second exceeded its initial full-inventory time bound before R started. Linux symlink-aware inventory with bounded process-group cleanup and parallel file hashing preserves the full scope. The first successful dispersion run then stopped on the probe writer's incorrect `monocle::sizeFactors` namespace; the corrected writer calls the actual exported `BiocGenerics::sizeFactors` accessor. A later summary flag was shadowed by a source-function variable; the selected rerun fixes only that metadata binding and preserves all scientific test tables. None of those earlier attempts is counted as a clean readiness pass.

These are original-source software controls on declared synthetic data. They do not reproduce the paper's unspecified patch, family, complete formula or biological findings. A typed Java adapter with complete admission/report/lifetime controls remains the next implementation step; no Monocle2 user analysis or catalog integration credit is inferred from successful R reference controls.
