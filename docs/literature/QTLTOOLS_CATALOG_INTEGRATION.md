## Warnings and required actions

**SKIP3 means the dependent analysis did not run.** Supply the named exact permitted
executable, libraries, inputs/indexes, Linux/WSL/Python utility or audit source.
Downloads/private installation are authorized where permitted. If installation is
prohibited, retain the skip and state the affected analysis and exact item needed.
Use [the runtime guide](QTLTOOLS_RUNTIME.md) for measured hashes and packages.
An unavailable source audit is also skipped; it cannot establish catalog admission.

**FAIL2 admits no complete analysis result.** Keep the complete raw capture, logs,
exit/signal, partial/null/failed exports and owned cleanup receipts. Resolve the
named data, numerical, capacity, process or integrity cause and retry NEW output.
Do not overwrite failed evidence, drop failed rows, repair NaN/Inf or replace an
unknown edition/settings with a convenient choice. An original exit0 can still
be a parsing failure; output completion and admission must also pass.

**Read `analysis-status.json` and `WARNINGS.md` before using results.** Completed
null results are labelled and do not imply an association, donor match or positive
expression. Original1.1 MBV integer fractions, edition-dependent trans-null-file
columns and the fdensity annotation-order guard remain explicit. A scientific
result check is distinct from a packet hash check or an authenticated producer.

**Keep private artifacts before changing machines.** The ignored original/current
JARs, upstream binaries/libraries, XML/PDF primary text, private author context and
complete historical/failed evidence require a separate checksummed transfer.
The [workflow transfer inventory](qtltools-workflow-development/PRIVATE-TRANSFER.json)
lists existing roots; retain this owner's `build/qtltools-catalog-1` as well.
