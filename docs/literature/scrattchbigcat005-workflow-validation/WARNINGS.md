# Warnings and required actions

**SKIP3: a missing or forbidden prerequisite skips the dependent analysis.**
Read the named cause in `WARNINGS.md`, `FAILURE.json` and the raw logs. Provide
the exact permitted Linux runtime, source snapshot, dependency artifacts and
writable paths described in the
[workflow guide](../../../tools/literature/scrattchbigcat005_workflows/README.md).
Installation and downloads require the explicit installer flags. Retry in new
paths after resolving the requirement; a skipped operation supplies no result.

**FAIL2: no complete result is admitted.** Preserve inputs, logs and partial
files. This includes an original operation that returned successfully when
recording its manifest or final completion marker subsequently failed. Correct
the named input, environment or recording problem and retry in new writable
paths. Only a final `COMPLETED.json` admits the recorded operation. Six
intentional controls retain actual upstream failures and no result.

**Choose a source profile explicitly.** The papers' actual Git commits and
caller environments are unknown, and P058 does not establish a package edition.
The 2023 snapshot retains a harmonization indexing error, a default-vector
mapping error and free-variable imputation defaults. The 2022 snapshot needs
explicit caller `sets`, retains R 4.1 warnings, and lacks `impute_cross_big`.
No fallback or repair of upstream algorithms occurs. Caller inputs and project
workflow choices must not be presented as recovered author settings.

**Retain original values, conditions and object differences.** Do not silently
drop IDs or coerce `NA`, `NaN` or infinity. Serialized FBM class identities,
cyclic plot environments and temporary Annoy paths can differ between
processes. Full objects and full comparison messages are retained. Independent
checks of scientific arrays, backing bytes and plot renders do not establish
live-pointer persistence or complete R-object identity. Source-produced blank
plot pages and warnings also remain unchanged.

**Use trusted RDS requests.** The adapter is not a sandbox for untrusted R
serialization or arbitrary user code. Synthetic scoped checks do not establish
biological validity, whole-paper reproduction or whole-tool qualification.
This evidence checkpoint does not admit BIGCAT into the catalog or finish the
250-paper project. Cell Ranger remains excluded at the user's request.
