# BIGCAT 0.0.5 scoped workflow evidence

**Read [WARNINGS.md](WARNINGS.md) before running an analysis.**
The [workflow guide](../../../tools/literature/scrattchbigcat005_workflows/README.md)
documents installation, explicit source profiles, requests and recovery steps.
This checkpoint adds no catalog family credit. The separate native Java
marker-doublet component and all of its earlier evidence remain unchanged.

The original-source controls contain 25 cases: 19 complete returns and six
original failures without admitted results. They exercise eight reported
function roles across two explicitly selected upstream snapshots, plus
cross-validation and constellation workflows. The evidence includes 3,198
scientific comparisons, complete R objects, original conditions and RNG states,
retained file-backed assets, and 15 PDF pairs containing 18 pages per side.
The rendered PDF pixels agree. Cross-process live R-object identity is not
claimed. These synthetic controls do not reproduce the papers' biological
results or establish whole-tool validity.

[QUALIFICATION.json](QUALIFICATION.json) records the source identities,
checks and qualifications. `original-workflow-and-installation-evidence.zip`
contains the complete logical index and inner qualification. All five
`payloads-*.zip` volumes are required. Identical file payloads are stored once;
the index maps every logical evidence file to its exact bytes. The verifier
checks all archive populations and payload hashes before interpreting results.
Installed binary prefixes are represented by complete inventories, original
source archives, locks and installation records rather than redistributed
runtime trees. Earlier failed development and packaging attempts remain
retained in the local development workspace.

[SAVED-REPLAY.json](SAVED-REPLAY.json) records the completed replay of this frozen
evidence. `REPLAY-RECORDS.zip` retains its complete comparison outputs, derived
renders, independent checks and process logs, with a full file manifest.
Replay reparses the captured Parquet data, recomputes independent
training means and comparisons, and renders retained plot objects. It does not
fit a new BIGCAT model. Use new writable output paths:

```bash
python3 -B tools/literature/scrattchbigcat005_workflows/verify_checkpoint.py \
  --runtime2023 /absolute/path/to/prepublication-2023-provider \
  --runtime2022 /absolute/path/to/pre-regression-2022-provider \
  --out /absolute/path/to/repository/build/literature-review/monocle-runtime/NEW-check
```

Both providers must first be installed or adopted using the workflow guide.
The check requires permitted Linux execution with the declared original
sources and dependencies. It retains complete comparison differences rather
than deleting opaque object fields to force equality.
