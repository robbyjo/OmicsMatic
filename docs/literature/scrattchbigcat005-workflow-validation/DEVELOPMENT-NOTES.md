# Retained development corrections

The first single-volume evidence candidate exceeded the selected repository
file budget. It remains in the local development workspace. Storage was changed
to five payload volumes with a complete logical index; no scientific result,
upstream source or historical verifier identity was changed to fit the budget.

Two subsequent packaging attempts stopped before producing a qualification
because a generated semantic-delta index used a scratch filename retained from
an earlier attempt. Their partial volumes and the captured failure log remain
under `build/literature-review/monocle-runtime/`. The packager now creates that
index inside its new evidence directory. An interrupted or failed archive is
not an admitted checkpoint.

An earlier derived PNG comparison created new Fontconfig cache entries inside
the protected runtime prefix. All 88 newly created entries were retained in a
separate quarantine, and the complete original runtime inventory was restored
exactly. Verification now writes font caches to its owned output directory.
Both failed and corrected comparison records, inventory differences and the
individual preservation receipts are included in the logical evidence tree.
Original saved source and runtime hashes were not refreshed.

Earlier constructor, source-profile and object-comparison failures are retained
as development history. The six final original-analysis failures remain
failures without results. Final qualification and saved replay are described
in [README.md](README.md), with limitations and recovery steps in
[WARNINGS.md](WARNINGS.md).
