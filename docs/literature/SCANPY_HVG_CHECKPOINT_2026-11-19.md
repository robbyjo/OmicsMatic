Seurat expm1/log-base inversion, equal-width and percentile binning, pandas
group reductions, statsmodels-scaled MAD, strict inequalities, top-count
precedence/ties, per-batch unexpressed filtering, aggregation and edition-specific
final tie ordering. AnnData's float32 normalized annotation is exported only
after selection; the DataFrame form retains float64. No source variance floor,
automatic normalization, generic NaN repair or alternate algorithm is added.

matrices, both flavors, dense/implicit-zero/explicit-zero CSR, cutoffs/top
counts, batches, log bases and export precision. All **2,560 original case
comparisons pass**, including exact gene masks/batch counts and numeric
comparisons within the declared tolerance. There are **1,632 original returns
and 928 original errors**. Degenerate/source-rejected inputs retain failure
rather than acquiring a repaired result.

The final normal Gradle JAR and isolated library each pass **2,574 checks on
Windows Java 21/25 and Linux Java 21**: 2,560 original cases and 14 independent
admission/boundary controls. All example runs pass. The library needs only
`java.base`; no upstream fallback production classpath is used. All **20,210
preceding class payloads and every previous JAR member's bytes remain
unchanged**; 12 native class payloads and new resources are added.
Both exact reference prefixes retain their complete original inventories:
25,252 legacy and 19,048 current entries, **44,300 unchanged in total**.

Explicit Seurat zero-variance missing annotations retain a named source
convention. Other invalid model arithmetic, negative variance, lost positive
