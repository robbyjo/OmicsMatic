Audit current source and the public evidence from the repository root:

```powershell
python -B tools\literature\metal_workflows\verify.py --out build\metal-audit-new
```

To rehash the complete private closure, add `--closed-evidence` with its path.
Add `--verify-bundles --java C:\path\to\java.exe` to actually run all 28
read-only Java verifications with the frozen reader and empty PATH. This still
does not execute METAL. Original-runtime replay is the separate explicit Java
`replay` command. Missing developer prerequisites yield SKIP3; changed code,
evidence or semantic admission failures yield FAIL2 with recovery actions.
