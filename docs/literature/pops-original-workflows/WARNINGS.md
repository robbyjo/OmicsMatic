# Original PoPS qualification warnings and required actions

This is bounded source-software qualification, not a complete tool/paper,
author environment or biological reproduction. New catalog credit remains zero.
Build current source; released v0.4.0 lacks these workflows. Old bundles require
their original matching artifact and runtime. Do not refresh saved fingerprints.

Missing/forbidden installation or runtime prerequisites mean SKIP3 and dependent
analysis skipped. Supply the named permitted Linux x86-64 setup or leave it
skipped. Source failures, convergence warnings and unmet capacity bounds mean
FAIL2 with no accepted complete result. Retain warnings, failures, raw reports
and process logs; correct the named cause and retry NEW output. Never thin inputs
or silently repair identifiers, nonfinite values, source defaults or covariance.

Only fresh process outputs admitted by the parent contract are results. The
private integrity suite deliberately retains altered input copies containing
forged completion markers. These are negative fixtures, not results. Expected
synthetic failures demonstrate refusal and require no repair of the test data.

Public-only readback verifies source/metadata only. Full saved-record readback
requires the exact named private files and upstream example data; it performs
no fresh model fit or runtime health check. Installed environments and caches
are excluded from the private archive scope. Setup byte/dependency manifests
are retained, but neither complete OS archival nor executable authenticity is
claimed. Runtime analysis must separately pass the configured current-host checks.
