# Saved native edgeR normalization qualification

Read the [method/file guide](../EDGER_NORMALIZATION.md) and
[runnable examples](../../../examples/edger-native/README.md) first. The component
is native Java; these saved independent original references do not become a
runtime dependency. Differential fitting, cumulative admission and the full
250-paper goal remain unfinished.

From the repository root with Python 3.11 or later and NEW output:

```text
python -B tools/literature/verify_edger_normalization.py --out build/edger-saved-readback-NEW
```

This reads saved evidence, checks live qualified source hashes and original
fixtures, and validates the exact recorded dispositions. It runs no R, Git,
JVM, model fitting, installer or analysis. Use `--jar PATH` optionally to compare
every decoded member of the particular qualified normal producer. This strict
whole-JAR check is separate from a component capture's own producer checks.

The packet binds normal Gradle compilation and 5,165 passing checks on each of
three JVMs. It contains independent normalization/CPM/RPKM records, composed
original-package example comparisons, saved-input arithmetic checks,
cross-host readbacks, actual replay path-alias controls and the 17-role primary
source census. The unchanged previous catalog is separately read back before
publication. That is a retained predecessor audit, not new family/review credit.

Original TMM/RLE/quantile functions are sourced unchanged for five exact editions.
CPM/RPKM uses stock current 4.10.7 and historical 3.40.2/3.42.4 packages, plus
declared original-kernel providers for 3.32.1/3.36.0. The latter compile unchanged
original C++ CPM/add-prior/object files and use unchanged original R matrix
helpers. They do not qualify a stock package or its GLMs. **The two full-package
R4.6 installation failures remain SKIP3**; supply a compatible separately
qualified runtime for those analyses. Original compiler and startup warnings

input library sizes lost precision. Current tests use the explicitly named v2
