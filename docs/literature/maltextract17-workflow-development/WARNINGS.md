# Warnings and required actions

**No whole MALT/HOPS or biological result is admitted.** These software controls
use public mitochondrial references and an explicitly selected HOPS taxonomy.
They are not the paper's spirochete collection, patients or dated database.
The paper's MaltExtract version and filter/resource choices remain unreported.

**Stock sampling can be hidden by an Off flag.** A complete10001-read original
RMA control demonstrated10000 examined reads with `downSampling? = Off`.
Retain the stock result, but skip full-population use. If complete extraction is
intended, explicitly select a complete profile and run a NEW output directory.
Disabling sampling, destacking and duplicate removal changes the method.

**Exit0 is insufficient.** The actual original program logged SEVERE output
write failures while exiting0 in the long-name control. The adapter retained
the failed outputs and refused admission. Inspect both process and original
error/log files. Unknown names and collisions refuse preflight; unavailable
runtime installation/execution produces SKIP3 with no dependent analysis.

**Keep original scientific values.** Original NaN/Inf and ragged rows are never
filled or repaired. Interpret supported tables only; dependent ragged-table
interpretation is skipped. The original damage denominator has a distinct
length>=20 gate and cannot be substituted with the filter alignment count.

**Checksums do not authenticate a producer.** Saved verification recomputes
input/selection/extraction consistency and checks fixed source-control oracles.
It does not rerun original Java8 execution or recalculate arbitrary upstream
damage/coverage statistics. Preserve the original files, all inputs and process
receipts; review the original statistical outputs before scientific use.

Required action: follow [README.md](README.md), use the exact permitted runtime
and complete supported inputs, select profile and provenance explicitly, and
provide sufficient capacities in a NEW directory. Install/download only where
allowed. If a needed prerequisite cannot be installed or executed, skip that
analysis and retain its prominent diagnostics. Resolve the named problem before
retrying. Do not silently rename taxa, truncate a population, change a method,
replace nonfinite cells or interpret a skip/empty extraction as biological absence.
