# Limma and voom catalog integration

Limma supplies one upstream implementation family. Voom is its validated family
alias and adds zero extra integration credit. Native Java variance components
belong to the same family. Generic differential APIs remain unchanged.

The source-built `limma-tools` command supports prepared-data LM, VOOM,
EDGER_VOOM_LMFIT, BATCH, NORMALIZE and CAMERAPR using the exact
limma 3.68.5 / edgeR 4.10.7 / statmod 1.5.2 / R 4.6.1 profile. All three packages
are required. See the [workflow guide](LIMMA_WORKFLOWS.md),
[executed examples](../../examples/limma-workflows/README.md),
[original qualification](LIMMA_WORKFLOW_QUALIFICATION_2026-11-21.md),
[global qualification](LIMMA_GLOBAL_CHECKPOINT_2026-11-21.md) and
[23-role source crosswalk](LIMMA_SOURCE_ROLES.md).
Build current source; the released 0.4.0 binary predates this command.

RUN retains original objects, failures, warnings and literal inputs. VERIFY checks
integrity, structures and selected arithmetic; it does not refit the model,
decode every RDS quantity or authenticate authorship. REPLAY uses new output and
preserves parent lineage. The qualified Java variance subset covers fitFDist,
legacy nonrobust squeezeVar, supplied-prior posterior, inverse trigamma and
logmdigamma. Modern/trend/robust model fitting uses the exact upstream runtime.

The guarded admission adds 18 limma and five voom reviews across 18 papers,
preserving all 1,575 earlier records. It adds limma observations to P088/P183/P203
and removes only P059's unreviewed historical stock-limma observation while
retaining scrattch. P237 remains edgeR-only. After admission the derived totals
are 142 families (26 native + 116 upstream), two zero-credit aliases, 2,717
observations, 1,598 reviewed uses and 1,119 pending. These are scoped integrations;
the complete implementation and paper-wide review goal remains unfinished.

Source limitations remain explicit:

- Older editions and exact paper-executed linked commits are not supplied by the
  current profile. P086 retains two methylation editions; P195 stays at the
  reported 3.44 label without an invented patch version.
- Dreamlet mixed models, ProStaR preprocessing and standalone voom-only/custom
  weighted residualization are not established by fitted-model qualification.
- P183/P203 linked source establishes relevant code roles, not author execution.
  P203's later quantile normalization uses preprocessCore and receives no limma
  normalization credit. That code-only finding needs a separate provider audit.
- P228 retains the author-reported voomLmFit/lmfit spelling and unresolved
  attribution. Its linked repository was publicly unavailable at the saved audit.
  No historical namespace or edition is silently substituted.
- Original-R Linux execution and independent Linux compilation are not claimed.
