# HOPS me_po warnings and required actions

**This is a scoped development operation. Catalog admission, whole HOPS/MALT,
author-setting recovery, manual biological authentication and the full250-paper
implementation remain open.** Read the [run/recovery guide](../HOPS_MEPO.md).

**SKIP3: a required exact runtime, allowed installation or native Linux execution
is unavailable. Skip dependent analysis.** Keep the failed attempt and diagnostics.
Prepare the exact Java8/MaltExtract and public R4.0.5 providers in NEW permitted
locations, or leave analysis skipped. Fitting also requires executable
`/usr/bin/python3`, `/usr/bin/setsid` and `/usr/bin/prlimit`; use permitted host
packages supplying those paths. Saved verification needs the exact1.7 reader
and public R provider. Do not substitute versions or infer analysis success
from installation/version probes.

**FAIL2: no result is admitted.** Inspect `FAILURE.json`, `WARNINGS_FAILURE.md`
and the named process's `process.stderr`. Retain every failed attempt. Resolve
the input, capacity, identity, process or scientific error and use a NEW output
directory. Do not edit saved evidence to make verification pass.

The original driver can exit0 after a child exits1. Two successful child exits
and complete output checks are required independently. Original fatal extraction
logs and failed/empty R plots admit no result. Insufficient evidence is
unassessable, not absence. Review original profiles and upstream warnings manually.

Stock `source-def-anc` retains original sampling, destacking and duplicate removal.
Assigned populations greater than10,000 can be prefix-sampled even if the original
downSampling? output says Off. The adapter preserves complete raw inputs and
warns about this source behavior. Selecting `complete-def-anc` deliberately
disables those operations and changes the method. Do not switch just to make a
plot or validation pass. Nonfinite values, original names and PDFs/RData remain
unchanged; unsafe identities or incomplete capacity are refused.

Saved verification freshly decodes RData and checks complete consistency. It
repeats no fitting/plotting and establishes no producer authenticity or biological
truth. SHA256 is integrity, not a signature. Original processing is qualified
under Linux JDK21, including the JDK25-built application; Linux JDK25 execution
is untested. Sampled RSS checks are not hard aggregate memory limits.
