# Original HOPS me_po development workflow

Use the [setup, fitting, verification and recovery guide](../HOPS_MEPO.md).

This adapter executes unchanged HOPS_Main from the GPL HOPS0.35 distribution,
its original MaltExtract1.7 child under pinned Java8, and its original AMPS
script under the public pinned R4.0.5 provider. Both source-def-anc and deliberate
complete-def-anc profiles are tested. Original child exits, complete extraction
outputs, all RData scientific fields, TSV and PDF populations are checked.
No upstream program, installed runtime, eager image or GATK binary is bundled.

**Catalog admission, whole HOPS/MALT qualification, author-setting recovery,
manual biological authentication and the full250-paper goal remain open.** This
development checkpoint adds0 catalog tool credits. The released/canonical
executable and root dispatcher are unchanged.

The complete logical evidence archive retains three original productions, two
independent original-launcher references, ten specifically rehashed semantic
refusals, four prerequisite/capacity/prefix controls, and the original empty-plot
failure where HOPS exits0 after its R child exits1. Source and complete profiles
match their independent originals across173 scientific files each, including
TSV, and280 RData fields each. The profiles differ in51 scientific files and
produce two versus four expected PDFs. PDF comparisons normalize dates only in
memory; original files remain intact. Raw RData workspaces remain intact.

All41 focused/adjacent tests pass on each of Windows JDK21 and25. Both compiler
builds target Java17 bytecode. Original application execution is tested under
Linux JDK21, including the JDK25-built application. Linux JDK25 execution is
untested. The initial producing source before an added fatal-log check is
retained byte-for-byte in the archive; current saved replay applies that stricter
check to the earlier productions. Compilation failures are retained as failed
build attempts and are not scientific results.

`controls.zip.xz` uses complete deduplicated logical files, not sampled rows.
`VALIDATION.json` binds source/archive identities. Public saved replay rebuilds
the application, restores every captured file, verifies all three complete
bundles with fresh RData decoding, rejects all ten intended contradictions and
checks retained original comparisons/failure. It repeats no fitting/plotting and
does not establish producer authenticity. SHA256 is an integrity check.

needed for fitting, while replay needs only the exact reader and R provider.
Install/download only where allowed; missing or forbidden prerequisites mean
SKIP3 and no dependent analysis. Retain every failed attempt and follow the
guide's named recovery steps. Stock prefix sampling, source nonfinite values,
empty/insufficient evidence and manual interpretation must not be hidden.
