# Original cell2location workflow: catalog evidence

This admission adds one scoped original upstream integration and six individual
paper-use reviews. It retains the fixed 250-paper corpus and all 2,671 software
observations. The resulting catalog has 110 new scoped integrations (20 native
Java subsets and 90 upstream workflows), 1,162 reviewed uses, 1,509 awaiting review
and 263 missing named families. The full implementation and review goal remains
open. The separate three existing adapters bring the integration total to 113.

Use the [installation, analysis and recovery guide](../CELL2LOCATION_CATALOG_INTEGRATION.md).

point with its own qualified private Linux/WSL environment. It is not included in
the released executable JAR. The [complete component evidence](../cell2location013-development/VALIDATION.json)
retains successful and failed development attempts, complete numerical stage
snapshots, raw original objects, warnings and process diagnostics.

files. `CENSUS.json` binds all 250 primary XML identities to the nine named
paragraphs. The six reviewed methods anchors remain distinct from the three
results/figure contexts. The source review preserves P096's paper/code differences

`cell2location-reviews-shared-source-compatibility.json`. Removing its exact
review-only delta reconstructs all preceding bytes and all 1,156 earlier reviews.
The original admission proof, scientific sources, outputs, archived evidence and
older verifier code remain unchanged. The failed cumulative check is retained;
it is not replaced by the successful fresh check.

Verify the current catalog from the project root without fitting or installing:

```sh
python3 tools/literature/cell2location_catalog/verify.py \
  --rescan-sources \
  --out build/literature-review/monocle-runtime/NEW-cell2location-catalog-check

  --out build/literature-review/monocle-runtime/NEW-cell2location-review-inverse-check
```

`finalize.py --write --out NEW-path` before the full cumulative verification.
Existing descriptors and evidence outputs are never overwritten.
