# Saved QTLtools workflow handover

Read the [handover](../HANDOVER_2026-11-21_QTLTOOLS.md) first. The workflow is
unfinished and receives zero catalog credit. The qualified fdensity API stays
available; the six drafts are saved outside production source/resource paths.

WORKTREES.json records61 existing owners' visible file variants,deletions and
staged patches. Storage points to immutable baseline Git blobs,the pinned prior
handover archive,or six new text blobs in deltas.zip. INVENTORY.json maps safe
load/help,intake metadata and compilation diagnostics to evidence.zip blobs.
PROFILE.json pins the packet,draft sources and unchanged canonical files.
PRIVATE-TRANSFER.json names excluded material needing separate private transfer.

Run `python -B tools/literature/verify_qtltools_handover.py --out NEW --restore`.
Python3.11+ and full main Git history are needed; --git selects the executable.
Copies go into NEW only. No patch is applied and no model or installer executes.
Hashes prove integrity,not authentication or scientific correctness. Original
historic readers remain frozen; run them on their actual unchanged owners.
