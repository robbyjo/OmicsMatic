# Velocyto counting qualification

This source checkpoint qualifies one scoped upstream counting family. Native
Java preparation and count-matrix APIs receive no additional family credit.
The [workflow guide](../../velocyto-tools.md) explains input contracts, integer
profiles, warnings and recovery. The frozen full 250 source audit supplies four
distinct reviewed [paper roles](../velocyto-source-audit/ROLES.json).

`QUALIFICATION.json` and `source-context.zip` bind the tested own source,
synthetic original controls and exact producing JAR identity. Original papers,
upstream software, private bindings, Loom outputs and raw traces remain private.
`COMPLETION.json`, when present, records publication, hosted byte readback,
verified compiler cleanup, recovery and a fresh post-cleanup original replay.
Qualification and completion are separate immutable records.

The qualification covers 20 native/contract tests on Windows and Linux, nine
complete original captures with independent upstream comparisons and fresh
replays, and 17 packaged prerequisite, preparation, integer, mask, capacity and
saved-evidence refusal controls. CLI and explicit original Counter API uint64
are different integer profiles. Six original pointsets exercise native matrix
audits, including the preserved original uint16 overflow and repeat-parser
discrepancies. A failed development ordering comparison is retained privately.

For historical verification after later changes, restore the exact archived
source context; do not refresh seals. Metadata integrity is separate from
independent scientific replication. Original counting is upstream, not a native
transcript-assignment replacement. RNA velocities, author recipes, complete
supplementary methods and whole-paper reproduction remain open. This checkpoint
does not publish a release binary or literature report to Pages. The full
250-paper implementation goal remains active.

**Warnings and required action:** missing or forbidden prerequisites produce
SKIP3 and skip dependent analysis. Supply/install the named prerequisite where
permitted, then use new paths. Invalid or changed bytes, failed data/model checks,
cancellation or capacity exhaustion produce FAIL2 and no complete analysis.
Keep every attempt, read the named audit and original logs, resolve its cause
and retry new paths. Cell Ranger stays excluded; MaxQuant runtime analyses stay
skipped and the tool pending.
