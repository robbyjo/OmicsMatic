# Public original Tomtom comparison workflow

The development `tomtom-tools` command runs complete original MEME Suite 5.5.9
DNA motif comparisons in explicitly requested `TEXT` or `FULL_REPORT` mode.
It includes separately permitted source setup, fresh current-host runtime health,
unchanged input capture, complete output auditing and portable bundle verification.
The [copyable example](../../examples/tomtom/README.md) explains setup and both modes.

```text
java -jar DEVELOPMENT_JAR tomtom-tools --export-runtime-setup NEW_KIT
java -jar DEVELOPMENT_JAR tomtom-tools --recipe REQUEST.json --home EXACT_HOME --build-evidence COMPLETE_BUILD_REPORT --out NEW_ANALYSIS
java -jar DEVELOPMENT_JAR tomtom-tools --verify COMPLETE_ANALYSIS
```

Fitting requires permitted Linux x86_64 Java, such as Linux Java inside WSL.

The recipe declares every exposed scientific choice: complete query and ordered
target databases, distance, pseudocount, minimum overlap, strand handling,
internal/complete scores, q-value or E-value threshold, background and output
mode. Input/output/native process capacities are explicit and checked before
launch. Arbitrary flags are unavailable. Safe staged filenames are command
carriers; original Unicode/spaced paths remain literal input provenance, and all
raw files remain byte-identical. No motif is silently filtered or renamed.

`TEXT` audits the original text table directly. `FULL_REPORT` requires original
XML, TSV and HTML and the original Perl/XML report capability. Every HTML data
field is checked against the independently audited XML: motifs/PWMs, database
identities, options, backgrounds, all matches, scientific values and metadata.
The HTML check does not certify browser security or execute its scripts. A failed
report helper never silently becomes text mode or another scientific run.

numeric values are **NA**, never zero or inferred biological absence. The original
q-value family contains tested target orientations beyond reported best matches;
do not recalculate q-values from the displayed rows. Original XML/TSV precision,
float32 conversions, printed-zero ambiguity, source preprocessing and small
