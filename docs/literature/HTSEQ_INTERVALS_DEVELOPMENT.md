# Native HTSeq interval-assignment development

`org.jlinalg.sequence.HtseqFeatureAssignment` supplies an immutable interval-set index and three documented assignment modes for already-derived aligned blocks. It supports the overlap operations needed by HTSeq gene counting and custom peak/region counting. This is a native Java foundation; a complete public HTSeq counting command and the paper-specific workflows remain unfinished. HTSeq receives no catalog implementation credit from this milestone.

Use the [checked Java example](../../examples/htseq-intervals/README.md). Build its separate executable with `-I tools/literature/htseq-core-development.init.gradle executableJar`. Java 17+ is sufficient for native execution. The actual-JAR matrix runs Windows Java 21/25 and Linux Java 21. Older released/canonical JARs lack the new API; the canonical executable remains preserved.

The reference is exact HTSeq 2.1.2 `GenomicArrayOfSets` step behavior, with the official union/intersection definitions applied to those original steps. [The official counting documentation](https://htseq.readthedocs.io/en/latest/htseqcount.html) distinguishes these modes and counting policies. The retained original step API was executed; this milestone does **not** execute an original `htseq-count` SAM/GTF analysis. Mode comparison establishes set resolution over original geometry, not the entire counting program.

`Interval` uses an exact chromosome string, a nonnegative zero-based inclusive start, an exclusive end, and strand `+`, `-`, or `.`. Long integer coordinates stay exact beyond 2^53; no floating-point coordinate conversion occurs. A stranded index accepts only `+` or `-` features/queries. An unstranded index combines both strands and reports `.`. Chromosome aliases, letter case and feature identities are never repaired. Feature IDs are strings; repeated IDs represent the same set member. Output ordering follows Unicode code points, including supplementary characters.

`Index.steps` returns complete maximal constant-membership spans, including empty gaps. `assign` resolves all supplied blocks with UNION, INTERSECTION_STRICT or INTERSECTION_NONEMPTY. Empty block lists yield no features; a zero-length block is refused as in the original set-array API. `NO_FEATURE`, `UNIQUE` and `AMBIGUOUS` describe the resulting set. They do not implement a downstream count allocation policy or establish biological absence.

**Required action after a refusal:** inspect the exception and original inputs, correct the named coordinate, strand, capacity or cancellation cause, then retry. No partial assignment or truncated result is admitted. Never silently drop a malformed/zero-length block or convert missing/ambiguous features into biological negatives. Library callers must retain their failed attempts; this API does not create an analysis directory or status bundle.

`Limits` bounds feature records, blocks per complete assignment, total overlapping feature records, event spans and labels. Defaults are 2 million features, 100,000 blocks, 2 million matches, 4,000,001 event spans and 2 million labels. Match and event-span budgets span the complete multi-block assignment. Event spans are counted before adjacent equal membership is coalesced. Zero match/label limits allow an empty result but refuse a feature overlap. These are logical population guards, not resident-memory guarantees. Cancellation or thread interruption admits no result; interruption does not clear the caller's flag. Built indexes/results are immutable.

**Scientific boundary:** callers must derive and declare CIGAR blocks, pairing, read/fragment units, strandedness transforms, mapping flags, MAPQ/NH filtering, secondary/supplementary treatment, nonunique policies, counting weights and reference/annotation identities. The API does not read SAM/BAM/CRAM/GTF, assign cell barcodes/UMIs, allocate fractional/random counts, normalize expression, call peaks or fit differential models. Full mutable HTSeq arrays, arbitrary Python object labels, old package environments and custom author code are not reproduced.

Validation retains 43 original populations with 538 successful queries, 1,214 complete original step spans, 1,614 documented-mode resolutions, 44 query refusals and 15 feature-insertion refusals. A further 337 candidate queries were not executed after their population's feature-insertion failure; they are not counted as passing original queries. Tests compare every step coordinate/strand and feature identity, plus bounds, immutability, whole-assignment budgets and cancellation. There are 2,224 passing actual-JAR tests without skips on each of three JVMs. All existing parent JAR entries remain byte-identical. This does not certify biological correctness or full paper reconstruction.

An all-250-paper census found eight HTSeq software uses: seven existing catalog entries plus P005's `HT-seq` 0.6.0 alias. Exact source archives 0.5.3, 0.6.0, 0.11.1, 0.13.5 and current 2.1.2 are retained with publisher-verified SHA-256. These source archives are not evidence of installed historical runtimes or paper-exact settings. P195 states only 0.13; P099 and P148 do not state an edition. Other papers omit effective flags and annotations. Their complete curation/public-workflow admission remains pending.

The 2.1.2 original reference uses an isolated Linux Python 3.12.3 environment with NumPy 2.2.6 and pysam 0.23.3. Downloads/installations were permitted; shared Python libraries were not modified. Installation and the version probe passed, then initial Windows metadata capture failed on Linux links. Recovery preserves that failure and a second directory-link handling failure, and captures the existing environment on Linux without reinstalling. A first collector was dependency-gated before execution; a second encountered the original zero-length refusal. Both attempts and their code/logs remain retained. The complete original control fixture explicitly includes those source refusals. The first evidence pack rejected a JAR directory-entry name; the corrected pack keeps the complete inventory and stores file payloads with directory entries checked separately. The incomplete packaging attempt remains retained.

**Missing/forbidden runtime policy:** Java-only native assignment remains independent of this Python reference. Future upstream-dependent HTSeq analysis must skip with SKIP3 if its required exact permitted runtime is missing or installation is forbidden, state the affected analysis and give exact provision/retry instructions. Setup completion alone admits no analysis. A malformed input, integrity, process or capacity failure must admit no partial result. Historical source functions are not silently translated to another Python edition or HTSeq release.

Source code and license are retained under `org/jlinalg/omics/htseq-intervals/` in the development JAR. SHA-256 establishes integrity, not signatures or execution authenticity. At this checkpoint, the catalog has 71 new scoped integrations, 74 including existing adapters, and 257 missing. Cell Ranger stays excluded. No release, push, deployment, complete project test suite, full-paper reproduction or whole-goal completion is claimed.
