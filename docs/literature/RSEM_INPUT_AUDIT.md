## What has been validated

The private Java input audit binds an exact protected alignment to a verified, source-built RSEM runtime. Original header inspection and decoding preserve the binary input for subsequent fitting. The native reader examines all decoded physical records and writes an independent expected parser projection. That projection matched complete original parser output populations in 478 retained successful cases across the five supported source releases.

CRAM requires an explicit local, uncompressed FASTA and its adjacent `.fai`. The audit checks complete FASTA/index agreement and header sequence identities and available MD5 values. It retains URI fields without fetching them. Header versus effective record length disagreements remain visible and block admission; the audit does not repair the header or replace the original binary with rewritten SAM.

Fresh live controls used RSEM 1.2.28, 1.3.0, 1.3.1, 1.3.2 and 1.3.3. All 45 positive input audits and 30 negative controls passed, with 2,460 physical records, 1,210 query groups and 265 original parser files compared. A controlled URI monitor observed zero reference requests. These runs reopened the previously verified source builds; they did not perform new compilation or new expression fitting.

The current package passes 228 focused tests on Linux Java 21. Windows Java 21 and 25 each pass 209 with 19 explicit Linux-only skips. Strict Java 17 compilation and private Javadoc pass. Existing scientific classes and every predecessor package member remain byte-identical. The live input checks used an earlier candidate; the validation record separately verifies that all of its package members are identical in the current candidate, which adds only fitting classes.

Typed fitting settings now preserve explicit auxiliary-tag behavior, release-specific strand arguments, unsigned seeds, read types and zero fragment-length standard deviation. Complete output auditing checks saved parser, count, model, theta, isoform, gene and directory populations. Those output checks pass against 22 retained original fits and their 364 scientific files. This is fixture validation of the new output auditor, not execution validation of the new typed fitting runner.

## Warnings and recovery

**A failed or unavailable dependency means the dependent analysis must be skipped.** Preserve `WARNINGS.md`, the named failure marker, original stdout/stderr, ledgers and partial files. The diagnostic identifies the cause and required correction. Supply the missing permitted runtime or local reference, correct the named input, integrity or capacity problem, and retry into NEW directories. Existing outputs are preserved.

Successful private audits do not certify convergence, study suitability, whole-paper equivalence, a public setup route or an operating-system sandbox. The retained control archive contains test summaries, profile reports, logs and controllers; complete private runtime trees and live scientific artifacts remain at the paths and hashes named by those reports. The archive is not a redistributable installed runtime or a complete portable rerun environment.
