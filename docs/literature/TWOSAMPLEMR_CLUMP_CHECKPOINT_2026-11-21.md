## Use, warnings and recovery

Start with the [adapter guide](TWOSAMPLEMR_LOCAL_CLUMPING.md) and
[copyable examples](../../examples/twosamplemr-clump/README.md). Runtime binaries
and R libraries are separate. Declare exact paths/profile/hash, all thresholds,
population provenance, seed, source-default opt-ins and original resource policy.

**Always read WARNINGS.md and analysis-status.json before using results.**
Source behavior is preserved: singleton bypasses can retain a SNP absent from
the panel or above threshold; original R can coerce numeric-looking SNP IDs;
text formatting can create P-value ties; zero variants is a completed empty
selection with no MR estimate. These outcomes receive specific warnings and
retained raw/parsed lineage. No SNP, allele, ancestry, threshold, precision,
duplicate, estimator or historical-version repair is performed silently.

**SKIP3** means a named exact permitted prerequisite is unavailable. Supply or
privately install it where allowed, or retain the dependent-analysis skip. If
installation/execution is actually prohibited, explain the restriction and
skip the affected analysis. Missing software is not an installation ban.
**FAIL2: NO COMPLETE RESULT** covers invalid inputs/design, integrity, numeric,
capacity, process or timeout failures. Preserve raw inputs/errors/partials,
correct the named cause and retry NEW output. PLINK rejection of `r2=1`, `kb=0`
and unsupported chromosome codes is retained. Use a NEW space-free output:
this Windows R version fails when its owned temporary path contains a space.
