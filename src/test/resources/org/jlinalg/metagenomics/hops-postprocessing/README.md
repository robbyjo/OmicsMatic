# Original HOPS postprocessing software control

`original-reference.zip` retains all37 original files from the public-R4.0.5
postprocessing of the complete10001-read MaltExtract software control, with a
portable literal-path index and SHA256 values. It also includes the complete six
tables consumed by the native statistics audit, the exact TSV/JSON, and an exact
double-bit export of the original RData. The RMA input is not duplicated here;
the complete original fitting inputs and process evidence belong to the separate
workflow qualification bundle. These are software controls, not biological data
validation or an author-parameter reconstruction.

The original script is the unchanged GPL HOPS0.35 distribution member
`postprocessing.AMPS.r`, SHA256
`7912dfcede0084134d1d677368f851a4d55dadeb0b7eaa591fcfe2e9c6cbdf62`.
Original attribution is retained in the HOPS/AMPS source; the exported workspace
and original plotting output remain unchanged. The source archive, R version
and exporter identity are recorded in the fixture's `SOURCE.json`.
