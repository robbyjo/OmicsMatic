# Original DESeq2 normalization reference

The retained loaded-function.txt contains estimateSizeFactorsForMatrix from DESeq2 1.52.0, by Simon Anders and DESeq2 contributors. DESeq2 is distributed under LGPL version 3 or later; the LGPL-3.txt copy is included here.

Official package: https://bioconductor.org/packages/3.23/bioc/html/DESeq2.html

Source archive: https://bioconductor.posit.co/packages/3.23/bioc/src/contrib/DESeq2_1.52.0.tar.gz

The archive hash, generated numerical controls and package session are retained in REFERENCE.json. Java implements a restricted raw-integer, median-location normalization subset. These controls do not establish historical paper-edition or whole-package compatibility.
