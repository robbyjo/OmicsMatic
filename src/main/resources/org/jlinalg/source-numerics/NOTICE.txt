Deseq2IndependentFiltering implements the source-specific default behavior of DESeq2 1.26.0 pvalueAdjustment (Michael Love, Wolfgang Huber, Simon Anders; LGPL>=3), genefilter filtered_p (Artistic-2.0), and R3.6.2 stats quantile/p.adjust (The R Core Team; GPL>=2). The Java implementation is GPL-3.0-or-later. Original package binaries are not distributed in this JAR. License texts are retained as reference notices.

The unchanged existing Deseq2SizeFactors Java source supplies the shared NA representation. Its presence does not certify all DESeq2 methods or editions. Complete source-specific controls cover the two new native methods and their declared finite-input/default-method scope. No whole-pipeline, fitted-model, biological or new catalog-tool admission is granted. Native computation requires no R installation.
