Native LeafCutter clustering/counts are a modified Java implementation following the original clustering/leafcutter_cluster_regtools.py, David Knowles, Yang Li and LeafCutter contributors, repository Apache-2.0, exact commit2c9907ef66adf0bfb3092f0ceb6886ee5c046fbb. Original source and complete control identities are retained. Python source is not patched. This component is not R/Stan differential splicing, phenotype normalization/PCA, junction extraction, historical paper binary parity or a full LeafCutter integration. R package code has a separate GPL>=3 declaration; it is not compiled by this component.
