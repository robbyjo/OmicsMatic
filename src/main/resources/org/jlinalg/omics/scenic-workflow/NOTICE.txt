SCENIC original-function orchestration and native activity composition

This profile composes unchanged original GRN/CTX functions and native Java
activity. Worker outputs remain provisional until the Java controller completes
its capture checks. Only fields marked eligible are numerically admitted; no
whole-paper or biological validity is established. Exact scope and independent
validation are documented separately from individual analysis captures.

The worker invokes installed, unchanged upstream scientific source. It does not
implement regression or motif statistics. Original pySCENIC 0.12.1 (commit
ce41b61b6570490949bd12b514e9f6de46d19c1f) and ctxcore 0.2.0 (commit
e68a0b168b9511efb3140c5cf1dd2b07bbd811cc) are GPL licensed. Their selected
source/license provenance and the NumPy notices are already packaged under
org/jlinalg/omics/pyscenic-ce41b61/. The installed pySCENIC _version.py is the
wheel-generated version module and differs from the corresponding Git-tag
template; its exact bytes are included in SOURCE-PROFILE.json. The other selected
installed pySCENIC/ctxcore Python files match the original source intake.

Arboreto 0.1.6 is BSD 3-Clause licensed; the exact official wheel license is
ARBORETO-LICENSE.txt. All four installed Arboreto Python sources match the PyPI
wheel with SHA256 6c70074b9d7273efaed0f89dd508c886b83c22ef81ae07ca923b7d21e7bbd057.
No whole upstream source archive, reference database or binary runtime is bundled
by this orchestration profile. The caller must supply permitted matching inputs
and runtime; missing/forbidden prerequisites skip the dependent analysis.

The task-ledger orchestration uses original infer_partial_network(include_meta
=True), modules_from_adjacencies, module2df/module2features_auc1st_impl,
MemoryDecorator, load_motif_annotations and df2regulons. The metadata return
distinguishes exhausted retries from successful fits with zero positive links.
CTX ERROR/CRITICAL logs prevent completion, including a swallowed MemoryError.
Native activity uses the separate qualified Java PyScenicAucell component.
Source checks, runtime fingerprints and SHA256 support integrity, not execution
authenticity or operating-system isolation. Keep all warnings and failed output.
