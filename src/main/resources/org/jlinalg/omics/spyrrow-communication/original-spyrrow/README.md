# Spyrrow

## Installation

### The recommended Python version for High-Performance Computing (HPC) environments
```
module load python/3.10.2
```

### Installation instructions
#### Method 1: From git
```
git clone 
pip3 install ./Spyrrow
```
#### Method 2: Download ZIP
```
cd /opt/
unzip Spyrrow-main.zip
pip3 install ./Spyrrow-main
```
### Once updated versions are available, please uninstall Spyrrrow and then proceed to reinstall the package using either Method 1 or Method 2
```
pip3 uninstall spyrrow
```

## Visium data visualization
### Load package
```
import scanpy
import spyrrow
```
### Data loading
#### Read Visium data using Scanpy (from the output folder generated by SpaceRanger), and then convert the data object into a Spyrrow object
```
adata = sc.read_visium('/opt/spaceranger_path/outs/')
spyrrow_adata = spyrrow.visium.Adata.SpyrrowData(adata)
```
##### The structure of a Spyrrow Visium data object is shown below
<img src="image/visium_spyrrow.png" alt="" width="300"/>

### SpaGCN clustering
```
spyrrow.visium.spaceGCN.call(adata = spyrrow_adata, n_clusters=8)
```
- `adata`: spyrrow anndata object
- `n_clusters` = 8
- `s` = 1
- `b` = 49
- `p` = 0.5
- `histology`: boolean, default is False
- `r_seed` = 100
- `n_seed` = 100
- `t_seed` = 100
- `group`: cluster index, necessary when setting the subset, default is None
- `subset`: the cluster to perform subclustering on, default is None

#### After calling spaGCN, you will obtain cluster labels in the 'pred' column, which can be checked through spyrrow_adata.obs['pred']
#### Users can further perform subclustering based on the clusters obtained from spaGCN analysis above
```
spyrrow.visium.spaceGCN.call(adata = spyrrow_adata, n_clusters=8, subset = [0,1,2])
```
#### After performing subclustering analysis with spaGCN, the results will be available in the 'sub_pred' column, which can be accessed using spyrrow_adata.obs['sub_pred']

### Visium data visualization
#### spatial plot of clusters
```
col_map = {-1:'grey',2: '#2ca02c', 3: '#d62728', 5: '#8c564b', 6: '#e377c2', 1: '#ff7f0e', 7: '#7f7f7f', 0: '#1f77b4', 4: '#9467bd',8:'#bcbd22',9:'#17becf',10:'#aec7e8',11:'#ffbb78'}
spyrrow.visium.visual.plot_category(adata = spyrrow_adata,group = 'pred',background=True, col_map = col_map,
                                    output = '/opt/output_name.png', figsize = (10, 10))
```
- `adata`: spyrrow anndata object
- `group`: cluster index
- `output`: output path
- `col_map`: color pre-setting for each cluster, default is None
- `subset`: which cluster to show, default is None
- `background`: whether to show the HE background, default is None
- `figsize`: figure size, default is (50, 50)
<img src="image/visium_cluster.png" alt="" width="300"/>

#### Users can ignore setting the colormap (col_map), as the function automatically assigns colors. However, it is recommended that users set the colormap in advance to customize their visualization results
#### This hexagon visualization may not work perfectly for every sample when setting 'backgroud = True', though it will work well for most ones. An updated version to address this issue is under development and will be available upon request

#### plot gene expression or other spot features
```
spyrrow.visium.visual.plot_continuous(adata = spyrrow_adata,variable = 'ACTA2',background=True, 
                                    output = '/opt/output_name.png')
```
- `adata`: spyrrow anndata object
- `variable`: a continuous variable for plotting, such as sample features or gene features
- `output`: output path
- `cmap`: default is turbo
- `group`: cluster index, necessary when setting the subset parameter
- `subset`: which cluster to show, default is None
- `background`: Whether to show the HE background, default is None
- `figsize`: figure size, default is (50, 50)

## Xenium data visualization
### Load package
```
import spyrrow

```
### Data loading
```
spyrrow_adata = spyrrow.sst.Adata.read_xenium('/opt/Xenium_output_folder/')
```
#### The Xenium output folder is the output from Xenium Analyzer instrument, which also contains the essential files for data analysis in Xenium Explorer
#### The structure of a Spyrrrow Xenium data object
<img src="image/xenium_spyrrow.png" alt="" width="300"/>

### Xenium data plotting function
#### spatial plot of categorical variables, such as cell clusters
```
spyrrow.sst.pl.plot_cell_patch(adata = spyrrow_adata,group = 'anno',col_map = cols,
                            output = '/opt/Xenium_cell_patch.png')
```
- `adata`: spyrrow anndata object
- `group`: cluster index
- `col_map`: a dictionary of the colors used for each cell type, the default is None
- `figure_size`: output figure size, default is (200,200)
- `subset`: a list containing cell types to be shown, eg, ['bcell','tcell']
- `output`: the output figure name, in the format of "absolute path + file name"
- `FOV`: the FOV to be plotted
- `FOV_col`: the column with FOV information
- `FOV_col_num`: the number of columns to put FOV images in for the final figure layout 
- `back`: background color, default is 'black'
- `back_img`: None or back_DAPI
- `move`: [left_move, top_move, right_move, bottom_move] for background figure match, default is [0,0,0,0]
- `img_scale`: scale factor for adjusting the size of the background image to be aligned with cell and transcript locations
- `Only_boundary`: fill the cell patch or only plot the boundary
- `boundary_width`: boundary width
<img src="image/xenium_cluster.png" alt="" width="300"/>

#### Users can incorporate Hematoxylin & Eosin (H&E)-stained images as background by reading the matched H&E data and integrating it into the data object.
```
image = spyrrow.sst.utils.load_image('/opt/matched_HE.png')
adata.uns['back_HE'] = image.copy()
```
#### Users can set the parameter back_img = 'back_HE'. Alternatively, users can always set DAPI-stained images as the background by specifying back_img = 'back_DAPI'. DAPI is added to the object when reading Xenium output.
#### It is recommended that users set the color map in advance. A legend describing the color map can then be generated using the following functions
```
spyrrow.sst.utils.plot_colorbar(adata,group = 'anno',
                                output = '/opt/color_bar.png')
```
##### or
```
spyrrow.sst.utils.plot_colorbar(adata,feature = 'ACTA2',
                                output = '/opt/color_bar.png')
```
##### or
```
spyrrow.sst.utils.plot_colorbar(col_map = col_map,
                                output = '/opt/color_bar.png')
```
- `adata`: spyrrow anndata object
- `group`: cluster index
- `feature`: gene name or other spot feature names
- `col_map`: when col_map is not None, adata, group, and feature can be None
- `output`: output figure name, in the format of "absolute path + file name"

#### spatial plot of both transcripts and cells
```
spyrrow.sst.pl.plot_RNA_on_cell(adata,RNA_name = ['MYH11','MZB1'],
                                RNA_name_col = 'feature_name',RNA_cell_id = 'cell_id',RNA_x_px = 'x_location',RNA_y_px = 'y_location',
                                RNA_size=10,col_map = cols,group='anno',
                                output = '/opt/RNA_within_cell.png')
```
<img src="image/RNA_on_cell.png" alt="" width="300"/>

- `adata`: spyrrow anndata object
- `group`: cluster index
- `col_map`: a dictionary of the colors used for each cell type, the default is None
- `figure_size`: the output figure size, default is (200,200)
- `anno_col`: in an annotated object, the name of the column containing cell type information
- `subset`: the cell types to be plotted, in a list, like ['bcell','tcell']
- `output`: the output figure name, in the format of "absolute path + file name"
- `transcripts`: the transcript metafile (pandas object), with columns documenting assigned cell, x_location, y_location
- `RNA_name`: the transcripts (gene names) to be visualized
- `RNA_color`: a dictionary of the colors used for each gene
- `RNA_size`: the point size for each transcript
- `RNA_name_col`: in transcripts object, the name of the column documenting gene names
- `RNA_cell_id`:  in transcripts object, the name of the column documenting cell IDs
- `RNA_x_px`: in transcripts object, the name of the column documenting X-axis coordinates
- `RNA_y_px`: in transcripts object, the name of the column documenting Y-axis coordinates
- `RNA_within_celltype`: only show transcripts within certain cell types, like ['bcell', 'tcell']
- `inside_dark_factor`: the darkening level of cell interior when plotting transcripts within cells, default is 0.5, 1 is to keep the brightness of cell interior and boundary at the same level; the higher, the brighter
- `scale_size`: Boolean: whether to scale the size based on transcript aggregation levels
- `patch_line_width`: the cell patch boundary width
