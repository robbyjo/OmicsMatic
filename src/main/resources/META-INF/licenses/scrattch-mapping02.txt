This dense numeric normalization component preserves the original zero-norm
branches, explicit dimensions, supplied names and nonfinite outcomes. It does
not perform nearest-neighbor search or hierarchical mapping. Java diagnostics
carry original warning message text, not complete R condition objects. R NA/NaN
payload identity and exact extended-precision sum bits are not claimed.
