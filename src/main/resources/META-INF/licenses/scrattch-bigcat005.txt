ScrattchBigcat005.findDoubletByMarker derives from find_doublet_by_marker
in R/find_noise_cl.R. It implements the plain dense numeric matrix,
character-marker-group and scalar-threshold operation. It does not
implement all of BIGCAT, recover an author's precise Git commit, or
reproduce a paper. Original source failures and dimension dropping are
part of this component's behavior.
