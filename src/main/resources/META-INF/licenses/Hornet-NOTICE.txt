The Java class org.jlinalg.sequence.HornetAlleles is a modified native port of
get_read_seqs, get_dual_read_seqs and reverse_complement. It uses HTSJDK CIGAR
decoding, immutable Java results and explicit native input/capacity checks.
Original sequence ordering, counters and described source quirks are retained
within its admitted domain. Cross-chromosome pairs and padded/nonmonotonic CIGAR
are rejected explicitly. It does not port the complete mapping pipeline.

The synthetic oracle fixture contains original-function results on project-owned
synthetic inputs, with exact source identity. Original Hornet implementation
files and the development runtime are not distributed in this project.
