OmicsMatic's native Java additive association implementation is adapted from the
modelLINEAR numerical behavior of Matrix_eQTL_main, row-mean imputation,
covariate projection, normalization, cis/trans testing and BH saver behavior.
Java adaptation copyright (C) 2026 OmicsMatic contributors, GPL-3.0-or-later.
Full corresponding Java source, project license and source-behavior notice:
https://github.com/robbyjo/OmicsMatic

No original R runtime or source file is bundled. Changes include strict ordered
input contracts, complete positive genomic positions, capacity/cancellation
refusal, FP64 Java CPU products, Householder projection, captured-input replay,
deterministic tie order and separately derived SE. This is an additive model
profile; ANOVA, interactions, graphical routines, direct-memory saver and author
paper recipes are not qualified. See docs/matrixeqtl-native.md and
LICENSES/MatrixEQTL-NOTICE.md in the corresponding source.
