Native Java finite float64 column-wise quantile normalization follows the
rank-target and tied-rank semantics of qnorm 0.8.0, by Maarten van der Sande.
Original project: https://github.com/Maarten-vd-Sande/qnorm
Copyright (c) 2020 Maarten van der Sande. MIT license; see LICENSE-qnorm.txt.

JLinAlg uses explicit finite-input validation and double arithmetic. It does
not implement qnorm's float32/int32 dtype behavior, ndarray axis0 orientation,
pandas, incremental or multiprocessing APIs. Bitwise NumPy/Numba parity is not
promised. Frozen references were produced by the original unmodified function.
