Original edgeR source profiles for prepared-count model workflows

The edger-workflow/source.zip resource retains unchanged selected R/C/C++
source, DESCRIPTION and NAMESPACE files from edgeR 3.40.2, 3.42.4 and 4.10.7.
Original authors include Mark D Robinson, Davis J McCarthy, Yunshun Chen,
Aaron TL Lun, Lizhong Chen and Gordon K Smyth; each source retains its
original attribution. edgeR is licensed under GPL (>= 2).

Exact archive URLs, source SHA-256 pins and original file pins are in
edger-workflow/SOURCE-PROFILE.json. Official package page:
https://bioconductor.org/packages/edgeR/

The OmicsMatic adapter and its R worker are GPL-3.0-or-later. The worker
uses the installed original package. Unchanged original glmFit, predFC,
glmQLFit, glmLRT and glmQLFTest bodies have explicit observational dense-matrix/
DGEList dispatch to retain/check full, prior-count, null and optional Poisson
fit objects; the original namespace is not modified.
This source bundle does not authenticate installed native DLL derivation
or qualify whole historical paper environments. No native fit is substituted.
